A native GUI for
Jujutsu Beta

Fast, keyboard-driven version control. Browse your DAG, review diffs, resolve conflicts — all from one window. Built with Rust + SwiftUI.

Download for macOS View source
$ brew install --cask hewigovens/tap/jayjay

Everything you need for jj

A complete visual interface for Jujutsu — from your first commit to production.

DAG Graph

Lane-based fork/merge rendering. Bookmark and conflict indicators. Revset filtering with preset chips.

Diff & Review

Unified + side-by-side with tree-sitter syntax highlighting. Word-level changes. Rename detection.

Conflict Resolution

One-click Use Ours / Use Theirs. Resolve in VS Code or Zed merge editor via jj resolve.

Interdiff

Shift-click two commits to compare. Full file diff with lazy loading between any revisions.

File Annotate

Syntax-highlighted blame gutter. Click any line to navigate. Full file history view.

AI Commit Messages

Generate via Codex CLI, Claude CLI, or Apple Intelligence. Auto-detected fallback chain.

Command Palette

Fuzzy search all operations. Inline jj CLI with ! prefix. Every action keyboard-accessible.

Editor & Terminal

VS Code, Zed, Xcode, Android Studio, Vim. Terminal.app, iTerm2, Ghostty. Auto-detected.

All jj Operations

New, edit, squash, split, graft, duplicate, merge, absorb, backout, abandon. Git push/pull.

Keyboard-first

Every action reachable without leaving the keyboard.
