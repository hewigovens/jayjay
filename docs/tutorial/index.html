JayJay in 12 seconds

The change graph and the diff, in one window. Three everyday jj workflows follow.

  1. Select a change in the graph
  2. Open its diff
  3. Jump to the working copy
  4. Open a file
  5. Mark it reviewed
Split

Split exactly the lines you mean

Pick hunks or individual lines from any file in the change, then split that selection into a clean child or parallel change.

  1. Open Edit Diff on a change
  2. Pick lines in two files
  3. Split them into a new change
Stacked pull requests

One PR per change, stacked

Right-click the tip of a linear stack and choose Create / Update Stacked PRs. JayJay names a branch per change, pushes them, and opens one GitHub PR, GitLab MR, or Cursor Origin PR per change with dependent bases.

  1. Right-click the top of a stack
  2. Name a branch per change
  3. One PR per change
Operation log

Undo anything

Every abandon, rebase, and split is an operation. Click the last one in the status bar, or press ⌘⇧U, to open the operation log and restore the repository to any earlier point.

  1. Abandon a change
  2. Open the operation log
  3. Restore the operation before it
