Diffs

Compare two changes

Shift-click two graph revisions to compare them. JayJay opens an interdiff using the same unified and side-by-side renderers as regular change review.

  • When both revisions have bookmarks, the compare banner uses bookmark names.
  • Use the direction control to flip the comparison.
  • Use bookmark diff when you want PR-style review against a main bookmark or fork point.
  • Use Compare Divergent Versions to inspect two commits that share one change-id before abandoning one.

Bookmark diff compares a feature bookmark against a base change or main bookmark.

Divergent compare shows the two commits that share a change-id before you abandon one.
