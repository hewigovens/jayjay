Conflicts

Resolve conflicts

Conflicted changes and files are marked in the graph and file list. Select a conflicted file to see available resolution actions.

  • Use inline Use Ours or Use Theirs when the file can be resolved that way.
  • Use Edit in JayJay to open a large, syntax-highlighted modal over the current detail. Two-sided conflicts show Base-relative Left and Right sources on top and each conflict once as a unified Left-to-Right diff below. Quiet Accept Left, Accept Right, and Accept Base links include hover help; -/+ stay in a non-editable gutter, and Option-Left or Option-Right applies to the selected hunk. Switch Result to Raw for direct, soft-wrapping marker editing. N-way jj conflicts remain editable through their markers, and partial resolutions can be saved while markers remain.
  • Your configured external merge editor remains available as a separate, explicit handoff.
  • JayJay refreshes after resolution so the graph and file list reflect the new state.

For direct CLI use, run jayjay config for the paste-ready tool definition, or choose Copy Config in Settings > Tools, then add it to your jj config.

Then run jj -R /path/to/repo diff --tool jayjay for a read-only comparison, jj -R /path/to/repo split --tool jayjay for interactive diff editing, or jj -R /path/to/repo resolve --tool jayjay path/to/conflicted-file for conflict resolution. jj edit selects the working-copy revision and does not accept a diff tool.

For Git, configure the same app as a custom diff and merge tool:

[diff]
    tool = jayjay
[difftool "jayjay"]
    cmd = jayjay tool diff "$LOCAL" "$REMOTE"
    prompt = false
    trustExitCode = true
[merge]
    tool = jayjay
[mergetool "jayjay"]
    cmd = jayjay tool merge "$LOCAL" "$BASE" "$REMOTE" "$MERGED"
    trustExitCode = true

Then run git difftool --dir-diff or git mergetool.

The conflict bar keeps one-click choices while adding JayJay's three-way editor and external-tool handoff.
