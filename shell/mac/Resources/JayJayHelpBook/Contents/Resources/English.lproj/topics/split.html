Changes

Split work from a change

Select a mutable change in the graph and a text file in its file list, then click Edit Diff in the diff header. In this editor, use a file’s checkbox to select the whole file, a hunk control to select its changed lines, or click individual changed lines in the gutter. The selection count shows what is checked.

  • File cards show +/− line counts and collapse in place; large diffs start collapsed. Expand All and Collapse All (⌥⌘E / ⌥⌘C) toggle every file, while j / k or the arrow keys move focus between cards, ← / → collapse or expand the focused card, Return toggles it, and Space selects its changed lines.
  • To split whole files, select them in the file list, right-click, and choose Split to New Change (or Split N Files to New Change). Enter a description in the sheet, optionally turn on Parallel split, and choose Split. You can also mark files reviewed with Space and use the split button above the file list to split those checked files.
  • In diff edit mode for a change other than @, enter a new description and choose Create New Child Change or Create Parallel Change to extract the checked edits. Move to Working Copy extracts them into @. The extracted edits leave the source change.
  • A child change builds on the source; a parallel change shares its parents. To turn existing changes into siblings, select them in the graph and choose Parallelize.
  • Done keeps the checked edits in the source and discards its unchecked editable edits, including edits in unopened file cards. This is the apply action available when editing @. Choose Cancel or press Esc to close without applying. Projected, renamed, and non-text files are preview-only. To recover a repository edit, use the operation log.
  • From the command line, jj split --tool jayjay opens the same blocking multi-file, line-selectable editor. Use jj diff --tool jayjay or a configured git difftool --dir-diff for a read-only directory comparison. See external tool configuration for the required CLI setup.

Diff edit mode lets you select files, hunks, or individual lines from the working copy or another mutable change.
