Diffs

Compare two changes

In an open repository, click the first change in the graph, then right-click the second change and choose Compare with selected. JayJay shows the differences from the selected change to the second one. Select a file in the resulting file list to read its unified or side-by-side diff.

  • The compare banner above the detail shows the two endpoints, using bookmark names when available. Click its opposing-arrows button (Reverse compare direction) to swap them, or its close button (Exit compare mode) to return to single-change review.
  • For PR-style review, choose Repository > Bookmark Manager (Cmd+Shift+B), right-click a non-trunk, non-conflicted bookmark, and choose Diff Bookmark. This compares its changes against trunk. Selecting a base change in the graph and choosing Diff Bookmark from a bookmarked target’s context menu uses that base instead.
  • A divergent change has multiple commits with the same change ID. Right-click one and choose Compare Divergent Version, or choose an entry from Compare Divergent Versions when there are several alternatives. Inspect the differences before deciding which version to abandon.
  • Shift-click selects multiple changes for batch actions. A consecutive direct-parent chain shows its combined changes; a selection that does not form one linear range has no combined diff. Use Compare with selected for an explicit comparison between two revisions.
