Bookmarks

Manage bookmarks and pull requests

A bookmark names a change; tracking connects it to a remote branch. With a repository open, choose Repository > Bookmark Manager or press Cmd+Shift+B to inspect bookmark state. Right-click a row for its available actions; Filter in DAG reveals its history and Diff Bookmark compares it against trunk.

  • To create a bookmark at a chosen change, right-click that change in the graph, choose Create bookmark here..., enter a name, and confirm. For an existing local bookmark, open the Bookmarks picker above the graph and right-click its row for Rename..., Move to @- (the working copy’s parent), Push, or Delete.
  • The Bookmarks picker in the graph header groups bookmarks as Tracked, Local Only, and Remote Only. Click a bookmark to select its change, or, when the graph does not show it, to narrow the graph to its stack and select it; choose a remote-only bookmark to browse that remote's history without creating a local bookmark. Filter by This Bookmark in a row's menu narrows the graph to the bookmark and its changes over trunk. The toolbar’s repository-wide Pull leaves tracking alone; an explicit bookmark Push or Pull can establish tracking for that bookmark.
  • To track a remote-only bookmark, right-click it in Bookmark Manager and choose Track name@remote. For a local bookmark, use Track Remote in its picker row’s menu when a matching remote bookmark is available. Tracking creates the local relationship used for synchronization; simply viewing a remote bookmark does not.
  • After a fetch or pull, a tracked bookmark whose remote branch was deleted, for example once its pull request merged, is cleaned up: its emptied changes and the bookmark go in one undoable operation. Changes with unmerged work, conflicts, or a workspace's working copy are kept, and Bookmark Manager marks the bookmark deleted on that remote.
  • Drag a bookmark chip in the DAG to move it to another change. Conflicted bookmarks use an orange warning chip on every target. Remove from This Change on that chip drops the bookmark from that change only; Bookmark Manager still deletes the whole bookmark.
  • For remote actions, configure a Git remote and credentials that allow pushing. Cloning a repository sets up origin; for an existing repository, use the command palette’s jj git remote list to inspect remotes or jj git remote add origin <url> to add one. Push the bookmark, then use its Pull Request on <forge> action in Bookmark Manager (available for tracked, non-trunk bookmarks) or its graph chip’s context menu to open or compose a GitHub PR, GitLab MR, or Codeberg PR. Cursor Origin has no compose page; JayJay creates a PR through the API when none exists, then opens it; sign in with origin auth login first. Create failures (GitHub-mirrored Origin repos, or a bookmark that is not on the remote) are shown as errors.
