Bookmarks

Manage bookmarks and pull requests

Open Bookmark Manager with Cmd+Shift+B to inspect bookmark state, reveal changes, copy names, diff bookmarks, and clean up stale bookmarks.

  • Use bookmark actions to create, rename, track, move forward, delete, or push bookmarks.
  • The Bookmarks picker in the graph header groups bookmarks as Tracked, Local Only, and Remote Only. Click a bookmark to select its change, or, when the graph does not show it, to narrow the graph to its stack and select it; choose a remote-only bookmark to browse that remote's history without creating a local bookmark. Filter by This Bookmark in a row's menu narrows the graph to the bookmark and its changes over trunk. Pull and Push leave tracking alone.
  • After a fetch or pull, a tracked bookmark whose remote branch was deleted, for example once its pull request merged, is cleaned up: its emptied changes and the bookmark go in one undoable operation. Changes with unmerged work, conflicts, or a workspace's working copy are kept, and Bookmark Manager marks the bookmark deleted on that remote.
  • Drag a bookmark chip in the DAG to move it to another change. Conflicted bookmarks use an orange warning chip on every target. Remove from This Change on that chip drops the bookmark from that change only; Bookmark Manager still deletes the whole bookmark.
  • Right-click a bookmark to open or compose a GitHub PR, GitLab MR, or Codeberg PR. Cursor Origin has no compose page; JayJay creates a PR with the origin CLI when none exists, then opens it. Create failures (GitHub-mirrored Origin repos, or a bookmark that is not on the remote) are shown as errors.

Bookmark Manager shows sync state, cleanup actions, and pull-request entry points.
