Tools

Use the command palette

With a repository open, choose Repository > Command Palette or press Cmd+Shift+P. Type an action’s name, use the Up and Down arrows to select a result, and press Return to run it; clicking a result also runs it. Esc closes the palette. Type help split to find and open local feature help.

  • With a change selected in the graph, search for Show Evolution, select the result, and press Return to inspect that change’s rewrite history. Choose Done or press Esc to return to the file diff.
  • Open the complete keyboard reference with Cmd+/ or Help > Keyboard Shortcuts.
  • For raw commands, install the jj executable and make it available on your PATH; Settings > Integrations shows whether it is detected. Type jj <args> or !<args>, for example jj status, and press Return. The command runs in the open repository. Input is passed directly to jj, so shell pipes are unavailable. Commands that need an interactive editor must receive their message inline, such as jj describe -m "Fix parser".
  • The result shows output and an exit status inside the palette. Choose Copy Output to copy it. Successful repository-changing commands refresh the repository view.
  • In raw jj mode, use Up and Down to recall commands from this session, then press Return to run the displayed command again.
