Tools

Use the command palette

Open the command palette with Cmd+Shift+P. Search actions by name, type help split to find feature help, or run raw jj commands inline.

  • Open the complete keyboard reference with Cmd+/ or Help > Keyboard Shortcuts.
  • Use jj <args> or !<args> to run raw jj commands.
  • Command output appears inside the palette and can be copied.
  • Command history is available during the session.
