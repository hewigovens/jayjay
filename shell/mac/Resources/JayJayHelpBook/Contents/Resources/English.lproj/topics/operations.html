Operate on changes

Use the detail header, context menus, or command palette to describe, commit, squash, abandon, duplicate, merge, absorb, back out, or revert changes.

  • The commit box describes and commits the working copy. It starts with the working copy's current description and preserves a typed draft when @ moves to an empty change.
  • Use a change's context menu to edit, squash, rebase, merge, duplicate, absorb, revert, abandon, or create a new change on top, before, or after the revision when its topology permits it.
  • Shift-click changes to select a batch, then merge independent heads, squash a consecutive linear range, abandon mutable selections, or rebase them onto another row while preserving their dependencies.
  • File actions can split selected files from a mutable change or move historical files into the working copy; commit and delete remain working-copy-only.
  • Commit messages can be generated through Codex CLI, Claude CLI, or Apple Intelligence when available.
  • Use Cmd+Shift+U to inspect the jj operation log and undo recent operations.

Undo uses jj's operation log so recent repository operations can be inspected before rollback.
