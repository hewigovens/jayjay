Pull requests

Create stacked pull requests

Open a repository whose origin remote points to GitHub, GitLab, Codeberg, or Cursor Origin, with credentials that allow Git pushes. The stack must be one linear chain of mutable changes above trunk, without merges or divergent versions. See Bookmarks and PRs for remote setup and Compare changes to inspect divergence.

GitHub, GitLab, Codeberg, and Cursor Origin requests use their APIs directly. For GitHub or GitLab, sign in from Settings > Integrations > Forges, use an existing gh auth login/glab auth login, or supply GH_TOKEN/GITHUB_TOKEN or GITLAB_TOKEN. Environment tokens take precedence over JayJay sign-ins, then CLI logins. Codeberg accepts CODEBERG_TOKEN/FORGEJO_TOKEN or a tea login add login. Cursor Origin uses the login from origin auth login; the CLI supplies credentials while JayJay performs PR operations through the API. Settings shows the active authentication source. For the browser-code sign-in steps, see Configure tools and settings.

Right-click the tip change of the stack in the graph and choose Create / Update Stacked PRs…. JayJay creates one PR or MR per change, each targeting the one below it.

  • The preview lists the tip change first, with each layer’s base beneath its bookmark name. Review the proposed names and PR titles; click a bookmark’s pencil to edit its name and press Return to finish, then choose Submit. Names must be distinct within the stack. Cancel closes the preview before submitting without publishing it.
  • Submit pushes bookmarks and creates or updates the dependent PRs or MRs. Done opens the top PR for a linked GitHub stack, always opens the highest submitted GitLab MR, and opens each submitted PR if GitHub native linking falls back.
  • Native linking uses the GitHub API; no CLI extension is required. If GitHub Stacked PRs is not enabled for the repository or rejects the chain, the dependent PRs remain usable and the result explains that linking was skipped.
  • GitLab detects the dependent MR chain automatically and shows a stack navigator in each MR; no separate linking request is required.
  • Codeberg stacks: set CODEBERG_TOKEN or FORGEJO_TOKEN, or use tea login add, with write access to the repository. JayJay creates or updates dependent PRs and adds links to the stack in each PR description.
  • Cursor Origin is still early beta. JayJay submits dependent pull requests through the API using your origin auth login credentials.
  • For ordinary GitHub PR chains, GitLab MRs, Codeberg PRs, and Cursor Origin PRs, merge bottom-up, fetch, then run Create / Update Stacked PRs again to retarget the remaining layers. For a native GitHub stack, use GitHub's stack controls; merging a PR also merges every unmerged layer below it, then GitHub rebases and retargets the remainder.
