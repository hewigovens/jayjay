Pull requests

Create stacked pull requests

Right-click the tip change in a linear stack and choose Create / Update Stacked PRs. JayJay creates one PR or MR per change, each targeting the one below it.

  • The preview lists changes bottom-first and lets you edit branch names before submit.
  • Submit pushes bookmarks and creates or updates the dependent PRs or MRs.
  • Merge bottom-up, fetch, then run Create / Update Stacked PRs again to retarget the rest of the stack.
