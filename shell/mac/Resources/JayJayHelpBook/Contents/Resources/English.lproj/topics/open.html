Getting started

Open a repository

Choose File > Open Repository... or press Cmd+O, then select a folder that already contains a jj repository.

  • After installing the bundled CLI, run jayjay /path/to/repo or jayjay . from a terminal.
  • The Repository List separates persistent Pinned repositories from Recent Repositories and groups recent sibling-workspace checkouts beneath their primary repository. Use the pin button to keep a repository in the list; clearing Recent does not remove pins.
  • Click the repository title to search this repository's workspaces, other open windows, pinned repositories, and recent repositories, or return to the full Repository List. Use Refresh in the picker to reload workspace state.
  • Create a workspace from Repository > New Workspace… or the command palette. A workspace row can open or copy the workspace name or checkout path, forget only the jj workspace metadata, or safely forget and delete the checkout after confirmation.
  • JayJay watches the repository and working tree and refreshes visible working-copy details after external changes. A refresh waits while an editor, review-note composer, or confirmation sheet holds unfinished input.
  • Onboarding, the Repository List, and each repository open in their own windows. Closing the last repository window returns to the Repository List automatically, and every window kind remembers its position and size across launches, as do the sidebar and file-column widths.
  • Recent repositories and Repository List… also appear in the Dock menu. Pinned repositories are shared with JayJay's GPUI shell, while each shell keeps its own recent history.
  • If the folder is not a jj repository, JayJay offers a jj git init path.

After opening a repository, JayJay shows the DAG, changed files, and selected diff in one window.
