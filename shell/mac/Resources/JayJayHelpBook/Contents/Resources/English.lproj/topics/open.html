Getting started

Open a repository

Choose File > Open Repository... or press Cmd+O, then select a folder that already contains a jj repository.

  • After installing the bundled CLI, run jayjay /path/to/repo or jayjay . from a terminal.
  • Recent repositories appear in the welcome window and the Dock menu.
  • If the folder is not a jj repository, JayJay offers a jj git init path.

After opening a repository, JayJay shows the DAG, changed files, and selected diff in one window.
