Inspection

Inspect file history and evolog

JayJay includes inspection tools for understanding where code came from and how rewritten changes evolved.

  • File Annotate shows blame information and lets you navigate to the responsible change.
  • File History lists revisions that modified the selected file.
  • Change Evolution shows prior versions of a rewritten change. Consecutive working-copy snapshots collapse into one row, Hide snapshots removes them entirely, and selecting two versions compares them directly.

Change Evolution makes rewritten snapshots visible without digging through the operation log by hand.
