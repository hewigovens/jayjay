Inspection

Inspect file history and evolog

JayJay includes inspection tools for understanding where code came from and how rewritten changes evolved.

  • Select a change in the graph, then right-click a file in its file list and choose Annotate (Blame). The annotate gutter shows each line’s author and responsible change ID; click that ID to select the change in the graph. Choose Exit Annotate or press Esc to return to the diff.
  • Right-click a file in the selected change’s file list and choose File History. A separate window lists revisions that modified the file, with the selected revision’s diff alongside it. Choose Pin as Base, then select another revision to compare the file between them. Swap reverses the endpoints; Clear or Esc clears the base. Right-click a revision and choose Show in Graph, or double-click it, to reveal it in the repository window.
  • Find a regression with Bisect… in the command palette, Bisect from here… in a change’s context menu, or Bisect between on two selected changes. Set Good and Bad endpoints, or enter a revset Range to use as-is, then choose Start. JayJay checks out candidates and highlights the search in the graph; mark each one Good, Bad, or Skip in the bar under the toolbar.
  • The bisect bar’s Run Test… control runs a shell command for this step or to the end. Exit status 0 means Good, 125 means Skip, 127 aborts, and other failures mean Bad. The bar shows command output and the result; its close button stops bisecting and restores the original working copy, reporting any temporary changes it kept.
  • Right-click a change in the graph and choose Show evolution… to open Change Evolution, which lists prior versions of that change. Select a version to inspect its diff. Consecutive working-copy snapshots collapse into one row, Hide snapshots removes them entirely, and selecting two versions compares them directly. Right-click a version to Restore this version into the working copy or the change you opened the evolog for, in one undoable operation, or to copy its commit id or a jj restore command; immutable changes cannot be restored. Choose Done or press Esc to return to the change detail.
