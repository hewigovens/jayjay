Diffs

Review changed files

Open a repository, select a change in the history sidebar, then select a file in its file list to read the diff. With the file list focused, press Space to toggle the selected file’s reviewed state. Reviewing records local progress; it does not change file contents or publish feedback.

  • The diff header shows a file-type or language icon, the file's status pill and added and removed line counts next to its name. Preview, the Unified/Side-by-side toggle, Edit Diff, and Edit File sit on the right and drop to icons when the pane is narrow; Tab reaches Edit File after Edit Diff. The command palette also toggles the diff layout.
  • The file list header puts its controls first and one count last: filter matches while filtering, review progress once a file is reviewed, otherwise the file total.
  • Moved code has linked line-number badges in unified and side-by-side diffs. Click a badge to jump to the matching block in the same file; its destination is briefly highlighted.
  • Binary sizes follow your locale. Hover over a size to see the exact byte count.
  • Use Cmd+F to search in the current diff.
  • Use Show 10 or Show all on an unmodified-lines row to reveal collapsed context in place.
  • Click a changed group's gutter stripe to review that hunk. File rows show unreviewed, partial, reviewed, or changed-since-review state.
  • Review marks are local and survive app restarts. A uniquely matching hunk stays reviewed across edits and rebases, so changing one hunk does not discard review work on the others.
  • Files whose marks came from an agent through the jayjay CLI show an agent badge and are counted in the reviewed-count tooltip until you take them over.
  • Click the eye button above the file list to hide reviewed files; click it again to show them. Click the magnifying glass there to filter by filename; Esc clears and closes the filter and Return keeps the query. To leave line-specific feedback, follow Review notes.
  • For changed working-copy text files, right-click a line number in either layout and choose Edit File at Line N to open the working-copy editor at that line. When the configured external editor supports line targeting, the menu also offers an action to open it at that line.
  • For a changed regular text file in the current working copy, use Edit File in the diff header. JayJay opens a large modal editor with syntax highlighting already prepared, soft-wraps long lines, and leaves the diff detail intact underneath; press Cmd+S to save or Esc to cancel. Historical, compare-mode, conflicted, removed, projected, and image files stay read-only, and JayJay refuses to overwrite a file that changed after the editor opened.
  • Use the rich preview icon for Markdown, SVG, notebooks, CSV/TSV tables, and SARIF reports when a rendered view is easier to read; a rendered SVG fits its own size and scales down to the pane. Text-backed files still open raw by default, so normal diff review remains available. Fenced mermaid blocks in rendered Markdown become diagrams using a bundled renderer, including offline; turn Preview off to return to the source diff. Working-copy HTML files render inline without running page scripts; the external-open icon launches the file in the default app for linked CSS and images.
  • Image files render as images. Drag the divider between the two versions to give either side more room; double-click it to reset.
  • Binary property lists open as XML with a banner. Plain XML property lists stay raw.
