Diffs

Review changed files

Use JayJay like a local pull request review. Step through the file list and press Space to mark the selected file reviewed.

  • Toggle unified or side-by-side diffs from the toolbar or command palette.
  • Use Cmd+F to search in the current diff.
  • Review marks are local and survive app restarts, but invalidate when the file content changes.
  • Hide reviewed files when you want to focus on what remains.
  • Use the rich preview icon for Markdown, notebooks, CSV/TSV tables, and SARIF reports when a rendered view is easier to read. Text-backed files still open raw by default, so normal diff review remains available. Working-copy HTML files use an external-open icon to launch the file in the default app, so linked CSS and images work normally.
  • Binary property lists open as XML with a banner. Plain XML property lists stay raw.

Review the working copy like a pull request: step through files and mark each one reviewed.
