Settings

Configure tools and settings

Open Settings to configure appearance, diff behavior, editor, terminal, jj settings, app metadata, fonts, and AI provider detection.

  • Adjust zoom with Cmd++, Cmd+-, and Cmd+0.
  • Choose external editors such as VS Code, VSCodium, Cursor, Zed, Xcode, or Vim.
  • Choose Terminal.app, iTerm2, or Ghostty for repository terminal actions.
  • Copy JayJay's jj diff/edit/merge tool definition from the CLI section, or print the same text with jayjay config.
  • The update channel dropdown in the About tab switches between Stable and Beta; the Beta channel receives pre-release builds through the regular update check.
  • Anonymous build and OS statistics are enabled by default and can be disabled here. JayJay sends no repository, file, or command data, and rotating identifiers cannot link an installation across months.
  • Choose Help > Send Feedback to email us.

Appearance controls theme, font family, and zoom.

Diff settings control layout, review behavior, and rendering defaults.

jj settings surface config paths and command availability.

Tools verifies command-line setup and copies JayJay's jj tool configuration.
