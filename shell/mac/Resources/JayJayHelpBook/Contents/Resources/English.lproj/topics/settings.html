Settings

Configure tools and settings

Choose JayJay > Settings… or press Cmd+, to open the window. Select a page in the settings sidebar: Appearance, Fonts, Diff & Files, Workflow, Integrations, Jujutsu, Data & Privacy, or About.

  • Appearance selects separate light and dark diff palettes and previews their colors. The active palette colors diffs, editors, and syntax highlighting. Wallpaper tinting is available with Default Dark; other dark palettes use their own background.
  • Fonts groups interface and code font families and sizes, code line spacing, ligatures, and a live diff preview. The ligatures switch is disabled for fonts that have none. Reset Fonts restores both font configurations; Cmd++, Cmd+-, and Cmd+0 change both sizes together.
  • In Integrations > Applications, choose an installed external Editor, such as VS Code, VSCodium, Cursor, Zed, Xcode, or Vim. Right-click a file and choose Open in <editor> to use it.
  • Choose Terminal on the same page, such as Terminal.app, iTerm2, or Ghostty. The repository toolbar’s terminal button opens that app at the repository’s folder.
  • Integrations configures editor, terminal, and AI commit-message providers and groups the jayjay/jj tools, the origin CLI, and detected authentication sources for GitHub, GitLab, and Codeberg. Tools and logins are checked in the background. Follow forge authentication setup if a forge shows Not signed in.
  • Under Integrations > Version control, click Install beside jayjay to link the bundled CLI at ~/.local/bin/jayjay. Add ~/.local/bin to your shell’s PATH, or use that full path directly. Copy Config beside jj tool configuration, or jayjay config, supplies the jj diff/edit/merge tool definition; follow external tool setup to install it in jj.
  • Diff & Files holds diff layout and rendering defaults and Auto-expand descriptions, which opens an overflowing description at its expanded height as soon as a change is selected. Workflow holds confirmations, including the Forget & Delete prompt after Don't ask again.
  • Jujutsu reads your jj user config files directly, grouped by section, and needs no jj binary; it shows Config not found for a missing file, or the load error and the file that failed, with an Open action.
  • In Jujutsu > Identity, choose Set Up… or Edit… to save the author name and email to your jj user config. The sheet shows the file it will update; saving refreshes identity displays in open windows.
  • The update channel dropdown in About switches between Stable and Beta; the Beta channel receives pre-release builds through the regular update check.
  • Data & Privacy shows how many review marks and notes are stored. Clear… beside Review marks and notes opens a confirmation; choosing Clear there removes them for every repository on this Mac. This cannot be undone through the repository’s operation log.
  • Anonymous build and OS statistics are enabled by default and can be disabled here. JayJay sends no repository, file, or command data, and rotating identifiers cannot link an installation across months.
  • Choose Help > Send Feedback to email us.
