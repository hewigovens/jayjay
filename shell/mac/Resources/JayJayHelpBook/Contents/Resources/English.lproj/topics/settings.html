Settings

Configure tools and settings

Settings is organized into Appearance, Diff & Files, Workflow, Integrations, Jujutsu, Data & Privacy, and About pages.

  • Appearance can disable Tint window background with wallpaper color for a neutral background.
  • Adjust zoom with Cmd++, Cmd+-, and Cmd+0.
  • Choose external editors such as VS Code, VSCodium, Cursor, Zed, Xcode, or Vim.
  • Choose Terminal.app, iTerm2, or Ghostty for repository terminal actions.
  • Integrations configures editor, terminal, and AI commit-message providers and groups the jayjay/jj and forge CLIs (gh, glab, origin); tools are checked in the background so pages open without waiting.
  • Copy JayJay's jj diff/edit/merge tool definition from Integrations, or print the same text with jayjay config.
  • Diff & Files holds diff layout and rendering defaults and Auto-expand descriptions, which opens an overflowing description at its expanded height as soon as a change is selected. Workflow holds confirmations, including the Forget & Delete prompt after Don't ask again.
  • Jujutsu reads your jj user config files directly, grouped by section, and needs no jj binary; it shows Config not found for a missing file, or the load error and the file that failed, with an Open action.
  • The update channel dropdown in About switches between Stable and Beta; the Beta channel receives pre-release builds through the regular update check.
  • Data & Privacy shows how many review marks and notes are stored and can clear them for every repository after confirmation.
  • Anonymous build and OS statistics are enabled by default and can be disabled here. JayJay sends no repository, file, or command data, and rotating identifiers cannot link an installation across months.
  • Choose Help > Send Feedback to email us.

Appearance controls theme, wallpaper tinting, font family, and size.

Diff & Files sets layout, review behavior, rendering defaults, and Auto-expand descriptions.

Workflow holds confirmations and repository behavior.

Integrations picks the editor, terminal, and AI providers and checks the jj and forge CLIs.

Jujutsu shows the jj user config JayJay resolved.

Data & Privacy holds statistics and stored review data.

About selects the Stable or Beta update channel.
