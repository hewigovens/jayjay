History

Navigate history

The graph shows jj changes as a DAG. Click a change to inspect it, or use j/k, arrow keys, and Ctrl+N/Ctrl+P to move through rows; Right/Left or l/h move from the graph to the file list and back.

  • The revset bar in the center of the title bar reads Revset on the default view and is tinted once the graph is narrowed. Click it, choose Repository > Filter by Revset… (Cmd+L), or use the command palette to edit it in place. Typing a preset or bookmark name picks that filter, jj's parse error shows before the graph reloads, Esc cancels, and the clear button returns to the default view.
  • As you type, the bar completes revset functions, your jj aliases, and bookmark, remote, and tag names at the caret. Down picks a suggestion and Return inserts it; Tab finishes the highlighted suggestion, or the first one. Return with nothing picked applies the revset as typed.
  • The filter icon at the start of the bar opens the presets (all changes, mine, bookmarks, tags, trunk, conflicts, and heads), the current revset, matching bookmarks, and this window's recent revsets.
  • Shift-click changes to select more than one. A consecutive direct-parent chain shows one combined diff. From a selected row's menu, merge independent heads, choosing which leads from the First parent submenu, squash a linear range, or abandon mutable selections; use another row as the destination to rebase the selection while preserving its dependencies.
  • Parallelize, from the context menu or the command palette, turns two or more mutable changes on one connected line into siblings: each keeps the parents it had outside the selection, and changes that sat on top of the run move onto every new sibling.
  • Drag a change row to preview and confirm a rebase. Dragging one change of a multi-selection rebases the whole selection. Rebase onto trunk in a change's menu moves its whole line of work onto trunk.
  • Drag a bookmark chip to move the bookmark, or drag the working-copy @ chip to edit another change. Dropping a resolved bookmark on the same change does nothing; dropping a conflicted chip on one of its rows resolves it to that commit.
  • A short description body takes only the lines it needs. The detail header shows a long description's first 80 points and scrolls; Expand shows up to 320 points while the file list and diff stay visible, and the summary with its Edit button stays put while the body scrolls.
  • Rows show name@ chips for other workspaces' working copies, so sibling checkouts are identifiable in the graph. Right-click a chip to open that workspace in a new window or copy its name or path.
  • Choose Show ancestors… from a change's menu to filter the graph to everything that leads to it; the revset bar keeps a Back control to restore the previous filter.
  • Press Tab to move keyboard focus through the graph, file list, description, diff, toolbar, and commit fields; Shift+Tab reverses, Space or Return activates the focused control, and Esc returns to the pane.

The DAG view is built around jj changes, bookmarks, conflicts, divergent changes, and revsets.
