JayJay Manual

JayJay is a native macOS app for working with Jujutsu repositories. Use it to navigate the change graph, review diffs, split work, manage bookmarks, create pull requests, and recover from recent operations without leaving the jj model.

Jujutsu, or jj, is a Git-compatible version control system. These task guides are available offline and can be followed without their screenshots. Online links provide additional illustrations and upstream documentation.

Use the sidebar or Help search to find a topic. With a repository open, press Cmd+Shift+P and type help in the command palette to search local feature help; select a result and press Return to open its topic.

Core concepts

  • A change contains file edits and a description. Its change ID stays the same as it is rewritten; its commit ID identifies one particular version.
  • The working copy, marked @ in the graph, is the change associated with this checkout. File edits become part of it automatically; there is no staging step. Describe or commit it when you want to name the work or start the next change.
  • A bookmark names a change. A tracked bookmark connects a local name with a remote branch for synchronization; see bookmarks and pull requests.
  • A revset is an expression that selects changes. @ selects the working copy; trunk() selects the main integration change configured for the repository. A change's parents are the changes it builds on.
  • Mutable changes can be rewritten. Immutable changes are protected by your jj configuration, commonly including shared history on trunk.
  • A workspace is a separate checkout with its own working copy that shares the repository's history. See opening repositories and workspaces.
