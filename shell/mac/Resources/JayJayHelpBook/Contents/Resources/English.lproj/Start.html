JayJay Manual

JayJay is a native macOS app for working with Jujutsu repositories. Use it to navigate the change graph, review diffs, split work, manage bookmarks, create pull requests, and recover from recent operations without leaving the jj model.

Jujutsu, or jj, is a Git-compatible version control system built around changes, revsets, an operation log, and flexible history editing. JayJay keeps those concepts visible instead of translating them into branch-first Git workflows.

Use the sidebar, Help search, or type help in the command palette to search these local task guides.
