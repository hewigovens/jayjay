Workspaces and file navigation

  • Filter the graph to a workspace from its picker row or graph chip. Open the current repository in Finder from the toolbar, Repository menu, or Option-Command-F.
  • External diff sessions keep their header visible while scrolling. Diff and merge sessions show readable errors when files cannot be loaded. jayjay tool --help prints usage without opening a session.

Diagnostics and review tools

  • Use Help → Reveal Logs to inspect the local log. Debug mode in Settings → Data & Privacy records additional snapshot and graph timings; beta builds enable it by default unless you have saved a preference.
  • With Debug mode enabled, Send Feedback attaches the log when Apple Mail is your default mail app, or reveals it for you to attach in another mail app. Review the draft and log before sending.
  • Syntax highlighting now supports PowerShell, Batch, INI, CMake, and XML-family files. A published JayJay Agent Skill helps coding agents work with your review notes and marks.
  • Updated dependencies include security and compatibility fixes.
