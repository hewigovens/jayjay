### Bisect, cloning, and file history

- Find the first bad change with Bisect from the command palette or graph menu. Mark candidates Good, Bad, or Skip, or run a test command for one step or to the end. The progress bar sits under the toolbar.
- Clone a Git repository from the welcome screen or File menu, with an editable name and destination and cancellation support.
- Set your jj author name and email in onboarding or Settings → Jujutsu.
- Compare two revisions in the File History window by pinning a base, selecting a target, and swapping endpoints. Show in Graph reveals the revision in the repository window.
- Create and update Codeberg stacked pull requests using CODEBERG_TOKEN or FORGEJO_TOKEN with repository write access.

### Menus, settings, and fixes

- Compare selected changes or divergent versions from the graph context menu. Bookmark menus can rename, pull, and choose a remote to track.
- Cancel an in-flight pull or push. More repository actions are available in the command palette, which opens after the current window action finishes.
- Data & Privacy can clear stored review marks and notes. File selection scrolls into view, including in tree mode, and Git LFS and submodule visibility settings are honored.
- Settings uses consistent typography, contributor avatars have reserved space, and empty or fully hidden file lists remain understandable.
- AppImages stay in the foreground under Firejail. Debian/Ubuntu packages for amd64 and arm64 are built and attached asynchronously alongside the AppImages and Arch packages.

### Windows portable alpha

- A Windows x64 portable ZIP and checksum are built and attached asynchronously to the release. Extract the ZIP and run jayjay-gpui.exe; install jj separately and keep it on PATH.
- The alpha requires Windows 10 version 1903 or later, or Windows 11. It has no installer or automatic updater; desktop rendering, scaling, authentication, and editor/terminal interactions still need broader Windows testing.
