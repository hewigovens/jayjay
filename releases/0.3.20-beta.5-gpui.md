### Fixes

- When another workspace rewrites this workspace's working-copy change, JayJay no longer snapshots the old files over the rewrite. The `@` row shows a warning glyph with an Update Workspace item, and Refresh updates the working copy like `jj workspace update-stale` until it is current.
- Refreshing the graph after a snapshot is about four times faster in repositories with thousands of changes, and diff line wrapping is roughly ten times faster.
- The Keyboard Shortcuts window, the sidebar toggle tooltip, and the conflict editor hints read their keys from the active keymap, so Linux shows Ctrl and Alt instead of macOS symbols. The window now also lists Repo Overview and the conflict editor's Alt-arrow keys.
- Fish scripts (`.fish`) get syntax highlighting.
