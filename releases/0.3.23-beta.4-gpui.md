## Divergent changes

- **Resolve Divergent Change…** in a divergent change's menu, and **Resolve…** in its detail header, open the same sheet as on macOS: keep one version whole or choose the description, contents, author, and parents card by card, then converge in one undoable operation.

## Editing and windows

- Ctrl+C, Ctrl+X, Ctrl+V, and Ctrl+A work in the command palette, find bar, pickers, and revset filter.
- The command palette scrolls to keep the selected command in view.
- Settings, Keyboard Shortcuts, and Clone focus their existing window instead of opening another, and every repository window remembers its size and position.
- Review marks are offered on every mutable change, and Settings can prune review data for changes that are no longer mutable.

## Fixes

- One unreadable value in `config.toml` no longer resets every setting; the original file is kept as `config.toml.bak`.
- A second quick save is no longer missed by the file watcher, and on Windows saving an existing file in place now refreshes the view.
- A failed load in the overview or annotate shows the error instead of an empty view.
- Bisect, pull request, and other remaining English badges follow the app language.
- First launch on Linux no longer suggests Homebrew for installing jj.
- A Scoop shim that cannot start jj now reports the underlying error.
