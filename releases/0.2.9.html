Image diff rendering

  • PNG, JPG, GIF, WebP, HEIC, BMP, TIFF, ICO, ICNS now render as actual images instead of <binary file> text
  • Side-by-side before/after for modified files; single pane for added, removed, and renamed
  • Pixel dimensions and file size shown under each pane
  • 32×32 icons render at 1:1 — no upscale-blur
  • Checkerboard background for transparent regions

SVG rich-view toggle

  • SVG files keep the text diff by default
  • Eye-icon toggle in the diff header switches to a rendered WKWebView view

DAG + file list keyboard navigation

  • j / ↓ / Ctrl-n → next change
  • k / ↑ / Ctrl-p → previous change
  • Same bindings work in the file list when it's the active pane
  • DAG receives focus on cold launch and new repo windows — no clicking required
  • Multi-window safe — only the key window's DAG responds to keys

Other fixes

  • Settings → Open jj config now respects the configured editor
  • jj fix config uses absolute paths so formatters work regardless of shell
  • Histogram diff algorithm (via similar 3.0) — matches jj diff and reads better on code than Myers

Internal

  • New extensible DiffPreview enum on DiffHunk — adding PDF/video preview is now a single enum variant
  • Test coverage for the image preview pipeline
  • update-appcast.py now prepends new entries instead of clobbering the entire file
