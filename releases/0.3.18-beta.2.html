Review with an agent

  • The jayjay command gains review status, review mark, and review unmark, so an agent can pre-mark the mechanical files or single change groups of the working copy and report what is left for you. status prints the commit it inspected and mark must hand that id back, so a mark is always tied to the content the agent actually read.
  • Files that include agent marks show an agent badge in the file list and are counted in the reviewed-count tooltip. An agent never takes over a group you reviewed, your own marks on a file take it back group by group, and unmark removes only agent marks.
  • jayjay review --help and every review subcommand print their usage.

Keyboard

  • Tab walks the whole window: graph, file list and its controls, description, diff layout, edit buttons, toolbar, and the commit fields, wrapping at the end; Shift-Tab reverses. Space or Return activates the focused control, Escape returns to the pane, and the active pane draws a stronger selection.
  • The file filter is a real search field: Escape clears and closes it, and Return keeps the query while handing the keys back to the list.
  • The description editor keeps the caret at the end when it takes focus, and Tab inside Diff Edit stays in the editor.

Settings

  • Settings is reorganized into Appearance, Diff & Files, Workflow, Integrations, Jujutsu, Data & Privacy, and About pages with a sidebar. Editors, terminals, AI providers, and the jj and forge CLIs live in Integrations; review data and statistics live in Data & Privacy.
  • Auto-expand descriptions in Diff & Files, off by default, opens an overflowing description at its expanded height as soon as a change is selected; the command palette toggles it too.
  • The Forget & Delete workspace confirmation has a Don't ask again checkbox, and Workflow restores the confirmation.
  • Jujutsu reads Config not found when there is no user config and jj is not installed when there is no jj, instead of showing a path to a file that does not exist.
  • Opening Settings and switching pages no longer stalls while tools are probed; the checks run in the background and their results are reused.

Diffs

  • Collapsed diffs are highlighted from the whole file, so a string or comment opened above a hidden region no longer mis-colors everything below it.
  • Word-level marks are skipped on rewritten line pairs, so a heavily changed line keeps its syntax colors instead of one solid highlight.
  • The status bar's file, insertion, and deletion totals match the detail header.
  • Expanding context that a running expansion already revealed no longer reports an error.
  • Changes to .gitattributes or the LFS index are picked up on the next refresh.

Faster and steadier

  • Moving the mouse across a large graph no longer re-derives its layout, and the layout arrives with the graph load instead of a second round trip.
  • Refreshes no longer spawn git and jj subprocesses; tags and LFS state come from the repository snapshot.

Fixes

  • Comparing a tagged change labels it with the tag before falling back to the change-id prefix.
  • Merge is offered whenever the two parents are independent, matching the Linux shell.
