### History navigation

- Follow the selected graph lane with j/k, Up/Down, or Ctrl-N/P, and switch columns with h/l or Left/Right. Tab and Shift-Tab move between panes, and the selected lane stays emphasized while the file list has focus.
- Stacks stay together with the working copy’s first, row dates use committer time, and the default graph filter honors jj’s `revsets.log`.
- Recent revsets are saved per repository, up to 15, and can be removed from the revset panel. Workspace names complete as `name@`, and bookmark chips, workspace chips, and workspace picker rows offer Filter by This Bookmark or Filter by This Workspace.
- Open the selected change or file’s context menu with the Menu key, Shift-F10, or Control-Return. The Repo Overview canvas accepts h/j/k/l, and Show Evolution is in the command palette.

### Bisect, cloning, and forges

- Find the first bad change with Bisect from the command palette or graph menu: mark candidates Good, Bad, or Skip, or run a test command for one step or to the end.
- Clone a Git repository from the welcome screen or File menu, and set your jj author name and email in onboarding or Settings → Jujutsu.
- Sign in to GitHub and GitLab from Settings with a browser code; GitHub and GitLab operations use their APIs directly with that sign-in, existing gh/glab logins, or environment tokens.
- Create and update Codeberg stacked pull requests with `CODEBERG_TOKEN`, `FORGEJO_TOKEN`, or a tea login. Cursor Origin PRs and stacks use its API with your Origin login.
- Cancel an in-flight pull or push. Bookmark menus can rename, pull, and choose a remote to track.

### Diffs

- Follow moved code between hunks with clickable line-number badges in both diff layouts.
- Compare selected changes or divergent versions from the graph menu; two revisions that cannot form a combined diff compare their endpoint trees.
- Renames come from jj’s copy records, and copies show as Copied and diff against their source. File lists and diff headers show file-type and language icons, and binary sizes follow your locale.
- A line-number menu in either diff layout opens the working-copy editor or a supported external editor at that line.
- Markdown previews render Mermaid diagrams offline, with source fallback for unsupported or oversized diagrams.
- File History compares two revisions of a file after you pin a base.
- Syntax highlighting adds PowerShell, Batch, INI, CMake, XML-family, and Fluent files, and TypeScript and TSX files again color keywords, strings, comments, and JSX markup.
- Tabs display as four spaces, fixing missing indentation in Windows diffs, and large files with many scattered edits no longer overflow the diff engine’s stack.

### Appearance, language, and settings

- Choose separate light and dark diff palettes, including Catppuccin, Dracula, Gruvbox, Nord, One, Solarized, and Tokyo Night, which also color editors and syntax highlighting.
- A Fonts page sets interface and code fonts, sizes, code line spacing, and ligatures with a live preview; changing fonts keeps the diff on the same line.
- Choose System, English, Japanese, Simplified Chinese, or Traditional Chinese in Settings > Appearance; most text updates immediately.
- Octicons and redrawn status badges make icons more consistent, the Settings sidebar is resizable, and pane handles are wider.
- Help → Reveal Logs opens the local log. Debug mode in Settings → Data & Privacy adds snapshot and graph timings and main-thread stall monitoring. Data & Privacy can also clear stored review marks and notes.

### Linux and Windows

- Opening repositories stays responsive while filesystem monitoring starts in the background, and watchers no longer follow symlinks inside the checkout. Font catalogs load in the background.
- Show in File Manager is in the Repository menu (Ctrl+Alt+F). Opening a subfolder resolves to its enclosing jj workspace, and Git-only or empty folders offer jj setup.
- Debian/Ubuntu packages for amd64 and arm64 are attached alongside the AppImages and Arch packages, and the one-line installer uses them on apt-based systems. AppImages stay in the foreground under Firejail.
- JayJay is in the [Microsoft Store](https://apps.microsoft.com/detail/9pjrq1hg25vb), and a portable Windows x64 ZIP is attached to this release. Window controls share the menu bar, and taskbar icons render without a background plate. Install `jj` separately on PATH.

### Fixes

- The change header credits co-authors from description trailers and a distinct committer, and forgetting a Git-backed workspace releases its Git worktree registration.
- Creating a bookmark or tag with a name git can’t store is refused up front, comparing against a remote-only bookmark works again, and Git LFS files with spaces or non-ASCII names are recognized.
- Review marks and notes saved by the app and the `jayjay` CLI at the same moment no longer overwrite each other.
- Updated GPUI and Rust dependencies include security and compatibility fixes.
