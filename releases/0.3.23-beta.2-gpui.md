## Review

- Clicking a file’s review mark, or the new **Mark Reviewed** button in the diff header, moves on to the next unreviewed file like Space. Marking a multi-selection with Space moves on too.
- SVG and SARIF files open rendered, and notebooks open as a text diff of their Markdown, with Preview and Source buttons.
- Pull request descriptions keep GitHub’s formatting tags, such as collapsible sections, tables, and lists.

## Gerrit and sync

- Changes on a Gerrit remote get **Upload to Gerrit** in the change menu; Pull abandons the empty copy a submitted change leaves behind, and an upload that would replace a newer patch set made in Gerrit is refused in favor of **Update from Gerrit**.
- Pull, push, and bookmark tracking follow `git.push`, or the only remote, instead of assuming `origin`.
- Built on jj 0.47.1: in colocated repositories, describing or rewriting the working-copy change keeps the Git staging area.

## SSH

- The Windows build now opens remote repositories over SSH, downloading and verifying the host’s helper on first connect like the Linux build.
- Reopening a remote repository whose checkout was deleted on the host reports it missing, and a canceled request to a host that stopped answering disconnects instead of waiting.
