This stable release brings together the improvements from six betas.

Remote repositories over SSH

  • Open a jj repository on a macOS, Linux, or Windows host from File → Open Remote Repository…. Choose a host from your SSH config, browse its folders, and work with the same graph and diff tools as a local repository.
  • JayJay downloads and verifies the host’s helper on first connect. The status bar shows the connection state and offers Disconnect and Reconnect. Remote working copies refresh automatically; review marks and notes stay on this Mac.
  • A disconnected write is never retried automatically. Unresponsive hosts disconnect when a request is canceled, missing checkouts report an error, and unused helper copies are cleaned up on the host.

Resolve divergent changes

  • Choose Resolve Divergent Change… from a change’s menu or Resolve… in its detail header. Keep one version whole, or choose the description, contents, author, and parents card by card, starting from jj’s automatic choices.
  • Preview the file differences and the descendants, bookmarks, and workspaces that will move, then converge in one undoable operation. Converge & Resolve opens the merge editor when the result needs conflict resolution.

Shortcuts and appearance

  • Settings → Keyboard Shortcuts lets you search commands, record new shortcuts, replace conflicts, and reset individual shortcuts or all of them. Menus, the command palette, and the shortcut reference follow your choices.
  • Built-in light and dark themes now color the whole repository window. Immutable changes appear as diamonds in the graph, as in jj log.
  • The new Flock settings page lets GitHub sponsors unlock a keepsake feather and extra Dock icons, also shown in About.

Review and editing

  • Review any mutable change. Clicking a file’s review mark or Mark Reviewed in the diff header moves to the next unreviewed file. A folder’s context menu marks its listed files reviewed or unreviewed, and Settings can prune review data for changes that are no longer mutable.
  • SVG and SARIF files have rendered previews, notebooks show a Markdown text diff with a preview, and ZIP-family archives show a file listing with checksums and sizes without decompression. Lua and extensionless scripts with a recognized shebang get syntax highlighting.
  • ⌘Z and ⇧⌘Z undo and redo repository operations, while text fields keep their own undo. History rewrites offer an Undo toast. Undo no longer rolls back working-copy snapshots and the disk edits they recorded.
  • Merge two or more selected changes, including an ancestor and its descendants, and choose the first parent. Change commands act on the selection and select their result.
  • Editors ask before discarding edits; failed loads offer Retry, and failed external-tool saves keep the window open. Diff Edit’s Keep Selected confirms before discarding unselected lines, and Abandon Selected Lines handles mixed added and removed lines correctly.

Gerrit, workspaces, and the command line

  • Gerrit remotes offer Upload to Gerrit and Update from Gerrit. Upload refuses to overwrite a newer remote patch set, and Pull cleans up the empty local copies of submitted changes.
  • Pull, push, and bookmark tracking follow the configured remote. Repository-specific jayjay.upload-command and jayjay.sync-command can replace Upload and Pull.
  • jayjay import <URL> imports a GitHub pull request or GitLab merge request into a sibling workspace. jayjay workspace add <name> creates one on trunk(); jayjay workspace prune removes landed or empty siblings while keeping pending work.
  • A workspace chip offers Rebase Lane onto Trunk. Rex opens terminal commands in a new tab, including when it needs to launch first.

Reliability

  • The detail pane stays steady during background refreshes, retaining unchanged diffs, comparisons, and multi-selections.
  • Squash, workspace creation, conflict application, and bisect follow working-copy snapshot rewrites instead of using stale revisions. Squashing a change into itself leaves it unchanged.
  • Bookmark names containing revset operators are handled literally. Stale-bookmark cleanup preserves never-pushed bookmarks and is undoable; stacked pull requests use the repository’s default branch.
  • Line-ending-only and trailing-whitespace edits remain visible. Unreadable sides of structured diffs keep their placeholders, and HTML previews without a declared character set use UTF-8.
  • File deletion and ignore-file additions stay inside the repository through symbolic links. SVG previews render as inert images, and the app bundles third-party license notices.
  • Built on jj 0.47.1, with faster bookmark and revset lookups and less repeated work in long diffs. Working-copy rewrites in colocated repositories preserve the Git staging area.
