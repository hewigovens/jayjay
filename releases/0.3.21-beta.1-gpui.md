### Fonts

- Interface and code fonts are now separate. Appearance sets the interface font family and size; a new Code Font page sets the code font, size, line spacing and ligatures, with a live preview and a reset that leaves the interface font alone. Existing settings carry over as the code font.
- The code font picker lists installed coding fonts first, then other monospaced families, including Nerd Font patches.
- Changing the code font, size or line spacing keeps the diff and editor on the same source line instead of jumping, in both diff layouts.
- Zoom changes both font sizes, and Appearance names the zoom shortcuts.

### Diffs and review

- Right-click a line number in either diff layout and choose Edit File at Line N to open the working-copy file in the built-in editor with the caret on that line.
- Renames come from jj's copy records, so a new file is no longer shown as a move of an unrelated file with the same name. Copies show as Copied and diff against their source.
- File status badges use icons: ± for modified and a copy icon for copied.
- In tree view, Space moves to the next unreviewed file in the order on screen and scrolls it into view, opening its folder if needed.

### Revsets and workspaces

- Recent revsets are saved per repository and kept after the window closes, up to 15, and each can be removed from the revset panel.
- Workspace names complete as `name@` in the revset bar, and a workspace chip's menu offers Filter by This Workspace.

### Fixes

- Creating a bookmark or tag with a name git can't store is refused up front instead of failing later.
- Comparing against a bookmark that exists only on a remote works again.
- Git LFS files with spaces or non-ASCII characters in their names are recognized.
- Onboarding opens in its own window, its last page includes the anonymous usage statistics checkbox, and no statistics are sent before onboarding finishes.
