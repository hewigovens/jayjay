## Keyboard shortcuts

- A new **Keyboard Shortcuts** page in Settings lists every command by context. Search or filter to modified ones, click a shortcut to record new keys, replace a conflicting one, and reset one or all.
- The keymap, menus, command palette, and shortcut reference follow your shortcuts; the palette shows each command's keys, and the reference lists only commands that have one.

## Appearance and Flock

- Built-in themes now color the whole window, not only diffs. Pick separate light and dark themes from Default, One, Gruvbox, Solarized, Catppuccin, Dracula, Nord, and Tokyo Night.
- The graph draws immutable changes as diamonds, as `jj log` does.
- A Flock page in Settings lets GitHub sponsors unlock the keepsake feather and choose the bird shown in About.

## Command line and packages

- `jayjay import <URL>` checks out a pull or merge request into a new `pr-<number>` workspace; `jayjay workspace add <name>` and `jayjay workspace prune` create sibling workspaces and delete landed ones.
- Windows releases include a native ARM64 ZIP alongside x64.
