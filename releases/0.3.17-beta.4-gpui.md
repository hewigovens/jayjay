### New

- Recent Repositories sit in a side panel beside the pinned list. It opens with your first recent repository, closes when the last one is removed, slides in and out from the button at the top left in between, and remembers the choice. The command palette gains a Repository List action.
- Pin or unpin a repository or workspace from the repository title picker, including the current one.
- Markdown previews render images inline: paths relative to the checkout, `data:` URIs, and SVG. The preview no longer draws a second frame inside the detail pane.
- Drag the divider between two versions of an image to give either side more room; double-click it to reset. This applies in the main diff and in Change Evolution comparisons.
- The light theme moves to neutral grays with hairline borders, file names, paths, and status tags take the weights and tints of the macOS app, and empty diff states get a title and subtitle.
- Launching from a terminal detaches the app, so closing the terminal or pressing Ctrl+C no longer kills it. `jayjay --foreground` keeps it attached for debugging; `--help`, `--version`, and `--repo` are available too.
- Arch packages ship with `.sha256` files next to the AppImage checksums, and stable releases sign the packages and the pacman repository.

### Fixes

- Editing the Recent list no longer flashes nested workspaces out and back in.
- Unpinning returns a repository to Recent instead of dropping it from the list; a nested workspace stays under its root.
- Shared with macOS: Solidity highlighting, no wasted highlight work when expanding files without a grammar, and Markdown centered images and table headers.
