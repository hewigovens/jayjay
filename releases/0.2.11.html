Status bar + GitHub PR integration

  • New extensible status bar with four item types: plain text, clickable link, action, and picker
  • GitHub PR status via gh CLI — shows PR number, state (open/merged/closed), and checks icon (passing/failing/pending) for the selected change's bookmark
  • Click the PR status to open it in the browser; hover to see the PR title
  • Workspace picker migrated to the new model with nested menu support
  • gh CLI version shown in Settings alongside jj

Post-fetch cleanup for merged PRs

  • After Git Pull, changes that are empty after rebase AND whose remote tracking branch was deleted are auto-abandoned — the PR was already merged, no manual cleanup needed
  • Conflicting changes in the same situation get flagged in the toast message so you can decide

Enum types + serde structs

  • PrState (Open/Closed/Merged), ChecksStatus (Passing/Failing/Pending/None), GhCheckStatus, GhCheckConclusion — all serde-derived, no string comparisons in the parse path
  • JJStatus renamed to CliStatus — shared between jj and gh CLI checks
  • types.rs split into types/ module with 7 focused files

Other fixes

  • Toast dismiss time now scales with message length (2–8 seconds) so long messages are readable
  • Toast tap-to-dismiss works on the full background area, not just the text
  • CI dedup: push trigger restricted to main — PRs no longer run duplicate checks
  • Docs: Myers → Histogram diff algorithm references corrected across README and landing page
  • Fixed broken Roadmap.md link in CONTRIBUTING.md
