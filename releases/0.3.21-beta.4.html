Follow moved code

  • Unified and side-by-side diffs now link code that moved between hunks. Click a line-number badge to jump to the matching block and highlight its destination.
  • File lists and diff headers show file-type and language icons. Binary sizes follow your locale, with exact byte counts on hover.

Preview diagrams and connect to forges

  • Rendered Markdown previews turn fenced Mermaid blocks into diagrams, including offline. Switch Preview off to review the source.
  • GitHub and GitLab operations call their APIs directly. Existing gh/glab logins still work; environment tokens also work without either CLI. Settings shows the detected authentication source.

Polish and help

  • Settings uses lighter sidebar icons, and the welcome screen has cleaner Open and Clone labels.
  • Offline Help is smaller, with complete task instructions that remain useful without screenshots.
