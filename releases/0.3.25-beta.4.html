See review progress at a glance

Turn on Review Mode for a change. The file list now shows how many files you’ve reviewed, and a thin green bar beneath the file list tools fills as you mark files. The count starts at zero so you can see the total before your first mark.

Fixes

  • File disclosure arrows, review checkboxes, copy buttons, and diff header actions are easier to click. You can click near the left edge of a file header to fold it.
  • You can now reduce the interface and code fonts to 8 pt.
