JayJay 0.3.24 is a small fix release.

- **Linux launch**: the app no longer exits at startup when fontconfig lists a font without an index, as on some Pop!_OS installs.
- **Fonts and text**: a font that fails to load is skipped in Settings, and a glyph that cannot be drawn no longer closes the app.
- **Forge actions**: pull request actions appear only for supported forges, and self-hosted remotes open in the browser with the right scheme and port.
