Colors and fonts

  • Choose separate light and dark diff palettes in Settings → Appearance, with a live preview. Built-in palettes include Catppuccin, Dracula, Gruvbox, Nord, One, Solarized, and Tokyo Night; the selected palette also colors editors and syntax highlighting.
  • A single Fonts page now groups interface and code font families and sizes, code line spacing, ligatures, and a live diff preview. Reset Fonts restores both font configurations.

Keyboard menus and editing

  • Press Control-Return in the graph or file list to open the selected change or file’s context menu. Navigate with arrow keys, use the menu’s letter shortcuts, and press Escape to return to the pane.
  • Right-click a line number in either diff layout to open the working-copy editor at that line, or open the same line in a supported external editor.

Credits and fixes

  • The change header now credits co-authors from description trailers and a distinct committer alongside the author, with duplicate identities combined.
  • Clicking the Dock icon restores a minimized repository window.
  • Forgetting a Git-backed workspace releases its Git worktree registration, allowing the path to be reused. Forget keeps checkout files; Forget & Delete still deletes only the verified checkout.
