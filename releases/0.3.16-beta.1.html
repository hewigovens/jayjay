Edit files and resolve conflicts in JayJay

  • Working-copy files can now be edited directly in JayJay: Edit opens a syntax-highlighted modal and saves straight into the current change.
  • Edit in JayJay resolves conflicts without leaving the app: Base-relative Left and Right sources on top, per-hunk Accept Left / Base / Right below, Option-Left/Right shortcuts, and a Raw mode for direct marker editing. Complete and partial resolutions both save, and n-way jj conflicts stay editable through their markers.

JayJay as a jj tool

  • JayJay now runs as jj's diff viewer, diff editor, and merge tool in blocking sessions; copy a paste-ready configuration from Settings > Tools or jayjay config.
  • Diff-edit sessions select individual lines, keep or discard whole binary and non-text files, and carry executable-bit changes; merge sessions reuse the in-app hunk resolver.
  • Closing a tool window cancels the session with the exit status jj expects, so an abandoned session never counts as an accepted edit.

Beta update channel

  • The new update channel dropdown in Settings > About switches between Stable and Beta; the Beta channel receives pre-release builds like this one through the regular update check.

Fixes

  • Actions that would rewrite immutable changes (edit, squash, rebase, abandon, describe) are no longer offered, and the core refuses them everywhere else.
  • An open conflict resolution now survives working-copy snapshots, and saving over a conflict that changed underneath is rejected instead of silently discarding the incoming side.
  • Repeated identical conflict blocks resolve at their own occurrence instead of the first match.
  • Image files, including SVGs, stay read-only in diff views, and renamed text files keep their Edit action.
  • The scroll wheel now reaches the surrounding list when hovering sized-to-content diff cards, and tool windows fit small displays.
