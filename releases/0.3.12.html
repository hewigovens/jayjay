Expand collapsed context

  • Collapsed "N unmodified lines" separators are now interactive: Show 10 reveals the next chunk beside the change and Show all expands the whole region, in both unified and side-by-side views.
  • Regions that fit in one chunk show a single Show all, and the links match the separator text until you hover — pointer cursor and hover underline mark them as clickable.
  • New command palette action Expand All Unmodified Lines expands every collapsed region of the visible diff from the keyboard.
  • Repeated reveals are fast on large files: syntax highlighting is computed once per file and reused, and revealed lines inside multiline constructs (like block comments) highlight correctly even when the opening marker is still hidden.
  • Expansion failures show as a small dismissible banner in the diff pane instead of a blocking alert.

Edit Diff mode for large changes

  • File cards collapse and expand individually, with per-file +/− line counts in each header and Expand All / Collapse All buttons (⌥⌘E / ⌥⌘C).
  • Large changes start collapsed automatically — over 30 files with more than 1,000 changed lines folds everything, and files over 300 changed lines fold individually — so entering Edit Diff on a big change stays instant and tidy.
  • Full keyboard flow: j/k or arrow keys move between file cards, ←/→ collapse or expand the focused card, Return toggles it, and Space selects its changed lines.
  • Select All is dramatically faster on moderate and large diffs.
  • Cards render full-height without nested scrolling, and binary property lists show their readable XML preview.

Fixes

  • Files that quote conflict markers (like documentation about <<<<<<<) no longer render conflict-styled or prevent context from collapsing.
  • Toggling Ignore Whitespace mid-action can no longer apply edits or expansions against the wrong version of a diff.
  • Scroll position stays anchored correctly when revealing context above the viewport, and in diffs with multiple conflicts.
