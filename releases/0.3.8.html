New

  • HTML changes can now be rendered inside JayJay in a sandboxed preview, including repository-relative styles and images, while the external-open action remains available.
  • Markdown previews now render repository-relative images, and rich previews use a compact, stable gutter.
  • The font picker recognizes a wider set of installed developer fonts.
  • The Dock icon now follows the system’s light or dark appearance.

Fixes

  • Repository windows opened from the repository list or Dock now appear at their normal size with the full toolbar immediately, without flashing a tiny intermediate window.
  • Closing the last repository returns to the repository list, and Dock menu actions now open the picker or recent repository reliably.
  • Window and diff resizing is smoother; large diffs rewrap after a live resize instead of on every resize tick.
  • Diff Edit and line-level discard now reject stale, conflicted, renamed, or immutable sources instead of rewriting unsupported or outdated content.
  • Bookmark drag targets remain available throughout the drag, and Escape closes Diff Edit.
  • The Conflicts filter now uses Jujutsu’s correct conflicts() revset.
