### New

- New Workspace from Pull Request (Repository menu and command palette) previews a GitHub pull request's remote, bookmark, and head, then fetches it into a sibling workspace or opens the one you already imported. Fields lock while it works, errors stay inline, and Cancel closes the sheet.
- Conflict panes scroll together from the same line map as macOS, number their lines, and bring the selected or accepted conflict into view in every pane.
- The SwiftUI polish pass: blue graph lines with aligned nodes, a chip row that collapses into a `+N` chip, status badges and rename paths in the file column, a description-first detail pane with an expandable byline grid, and per-file added/removed line counts in the file list and diff header. Hide and show the history sidebar from the toolbar, the View menu, Ctrl+Alt+S, or the command palette.
- Tab and Shift-Tab cycle keyboard focus through the visible panes, controls, and text inputs with an accent ring; Space or Return activates and Escape releases focus.
- Agent review marks: `jayjay review status`, `mark`, and `unmark` let an agent pre-mark mechanical files or change groups of the working copy, shown with an `agent` badge.
- Settings uses the same seven pages as macOS. Integrations holds the editor and terminal choices, codex and claude, the jj and forge CLIs, and the Linux `jayjay` install; Diff & Files adds Auto-expand descriptions.
- The description preview fits its content up to 80 points and expands to 320, and the description dialog reuses the commit box's fields. SVG previews fit and clip to the pane and rasterize off the UI thread.

### Fixes

- Every window shows readable jj and git errors instead of the raw command-failed chain.
- Long dialog subtitles, such as a New Workspace destination path, truncate inside the dialog instead of overflowing it.
- Load more works after a custom default revset, bookmark comparisons are labeled PR Diff, and a reviewed hunk's gutter stripe uses the accent color.
- Shared with macOS: faster opening and refreshes, whole-file highlighting for collapsed diffs, word-level marks skipped on rewritten lines, appended lines no longer shown as a changed last line, and faster conflict loading.
