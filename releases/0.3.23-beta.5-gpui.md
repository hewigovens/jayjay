## Undo and redo

- **Ctrl+Z** and **Ctrl+Shift+Z** undo and redo jj operations in a repository window; on Windows **Ctrl+Y** also redoes. Both are in the Edit menu and the command palette, and can be rebound in Keyboard Shortcuts.
- Every history rewrite shows an **Undo** toast that undoes exactly that operation.
- Text fields keep their own undo and redo while they have focus.

## Diffs

- Lua files are highlighted, and a script with no file extension, such as `bin/tool`, is highlighted by the interpreter named on its `#!` line.

## Fixes

- With unsaved edits in the working copy, squashing into a chosen change, applying a merge editor result to a change other than `@`, and starting a bisect between two changes now act on the current version of the change instead of leaving a divergent copy behind.
- Squashing a change into itself does nothing instead of rewriting it with a doubled description.
- On Windows, a Scoop-installed jj starts when Windows refuses to follow Scoop's `current` folder link.
