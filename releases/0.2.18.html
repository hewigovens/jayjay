Diff polish

  • New Unified / Side-by-side toggle in the diff header — replaces the icon-only toggle so the active mode is unambiguous.

File list polish

  • Tree mode now supports folding directories: click a folder row's chevron to collapse, click again to expand. Fold state is per-window and survives change selection.
  • Hidden the always-on system scrollbar on the DAG and file lists (no behavior change beyond visual quiet).

Fixes

  • Fixed duplicate folder rows in the tree file list — directory entries now carry their full path so SwiftUI's ForEach can key them uniquely.
  • About window: Sponsor / Star on GitHub buttons no longer pick up the macOS default-button accent highlight on open.

Internal

  • DAG lane assignment moved to jayjay_core::dag (Rust). The Swift DAGLayout is now a thin uniffi wrapper, so the lane logic is shared with future shells.
  • jayjay-uniffi split into per-feature modules (dag, diff, error, repo, types); lib.rs is a thin umbrella.
