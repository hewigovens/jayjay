Native GitHub pull request stacks

  • Submitting a GitHub PR stack now links its pull requests into GitHub's native stacked-PR experience, including the stack overview and merge-as-a-stack controls.
  • After submission, Done opens the top pull request for a linked GitHub stack or the highest merge request for GitLab. If GitHub native linking is unavailable, the existing dependent pull requests remain usable and JayJay opens each one.

Fixes

  • Edit Diff stays responsive while selecting or deselecting lines and scrolling, including large files with syntax-highlighted comments.
  • The running app's Dock icon now follows the system's light or dark appearance while preserving the development badge in debug builds.

Compatibility

  • Updated JayJay's embedded Jujutsu libraries to version 0.44.0.
