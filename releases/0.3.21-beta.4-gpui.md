### Clearer diffs

- Follow moved code between hunks with clickable line-number badges in unified and side-by-side diffs.
- File lists and diff headers use Seti file-type and language icons. Binary sizes follow your locale, with exact byte counts on hover.

### Forge access and polish

- GitHub and GitLab operations use direct APIs with existing gh/glab logins or environment tokens. Settings shows the detected authentication source; either CLI is optional when a token is available.
- Codicons replace the interface icon set for a more consistent developer-tool appearance.
- Short single-line inputs stay centered instead of scrolling while typing, and the welcome screen has cleaner Open and Clone labels.
