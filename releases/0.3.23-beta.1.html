Remote repositories over SSH

  • Choose File > Open Remote Repository… or search the command palette to open a jj repository on another machine. Pick a host from your SSH config or type one, then browse to its folder. A folder that is not a repository yet offers jj git init.
  • macOS, Linux, and Windows hosts are supported. On first connect JayJay downloads the small helper it runs on that host and checks it against this release.
  • The status bar shows the host’s platform and connection state, with Disconnect and Reconnect. While disconnected the repository stays on screen, and JayJay never retries a write on its own: reconnect and refresh first.
  • Remote working copies refresh on their own, like local ones. Review notes stay on this Mac; JayJay checks them against the host’s diffs here.

History and workspaces

  • A workspace chip’s menu in the graph offers Rebase Lane onto trunk, as in Repo Overview.

Safety

  • File deletions and ignore-file additions stay inside the repository even through symbolic links, image previews use a private cache, and SVG previews render as inert images.
