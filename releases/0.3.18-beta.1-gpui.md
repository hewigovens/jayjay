### New

- The description preview fits its content up to 80 points and scrolls beyond that; Expand shows up to 320 points while the file list and diff stay visible, and the summary stays put while the body scrolls. Empty mutable changes offer Add description.
- The description dialog reuses the commit box's Summary and Description fields, keeps the working-copy draft, preserves unchanged formatting and indented bodies, and Tab / Shift-Tab move between the two fields.
- SVG previews fit and clip to the pane, rasterize off the UI thread at viewport resolution (capped at 2048 pixels per side), and follow the theme for unspecified `currentColor`; explicit colors and CSS are kept.

### Fixes

- Inactive diff-header toggle buttons no longer draw a filled background.
- Shared with macOS: fewer loads when opening a repository, immutable history and workspace file counts cached between refreshes, and one definition of the trunk-bookmark rules for both shells.
