Working copy fidelity

  • Auto-snapshots now respect Git's full ignore stack — local .gitignore, core.excludesFile, the default $XDG_CONFIG_HOME/git/ignore, and .git/info/exclude. Globally ignored files like .claude/ no longer appear as untracked changes in the working copy.
  • The macOS filesystem watcher now consults the same ignore matcher as the Rust core, so editing a globally-ignored file no longer triggers a stale "uncommitted changes" indicator.
  • Tracked files that match an ignore rule still surface change events, so edits to checked-in build artifacts continue to refresh the UI.

Commit box fix

  • The commit message now resets after a successful jj commit, so the new working copy starts with an empty draft instead of inheriting the previous message.
  • If a commit fails, the draft is preserved — previously the box was cleared optimistically and the message was lost.

Release tooling

  • just release now stops at the local artifact (zip + signed appcast); the new just shell::publish recipe creates the GitHub draft, uploads the zip, and bumps the Homebrew tap. gh release create uses --verify-tag, so publishing aborts cleanly if the v<version> tag has not been pushed.
  • Sparkle signing failures now fail the release outright instead of producing an unsigned appcast entry.
