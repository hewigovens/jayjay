Undo and redo

  • ⌘Z and ⇧⌘Z undo and redo jj operations in a repository window; text fields and editor sheets keep their own undo. Every history rewrite shows an Undo toast that undoes exactly that operation.
  • Undo Last Operation is now Operation Log, and opens with the operation before the current one selected.

Changes and selection

  • The context menu, command palette, and Repository menu offer the same commands, and items that would do nothing are disabled. A rebase, duplicate, revert, squash, or abandon selects its result instead of jumping to @.
  • Rebase onto Trunk rebases the selected change, and the Abandon shortcut abandons every selected change.
  • Review marks are offered on every mutable change, not only @. Settings can prune review data for changes that are no longer mutable.

Divergent changes

  • When converging is expected to conflict, the sheet offers Converge & Resolve and opens the merge editor on the first conflicted file. A divergent change’s detail header has a Resolve… button.

Editors

  • Esc or Cancel asks before discarding edits in the merge and file editors. The merge editor labels each side with jj’s own labels, and picked hunks can be undone and picked again.
  • Diff Edit’s remove action reads Keep Selected and confirms before discarding unselected lines. Abandon Selected Lines now abandons exactly the lines you selected when a block mixes removed and added lines.
  • A failed save in the external diff tool keeps the window open with the error, and a diff, annotation, or file history that fails to load shows the error with Retry instead of an empty view.

Fixes

  • Pushing or fetching a bookmark whose name contains |, &, or ~ no longer matches other bookmarks.
  • A skipped GitHub check counts as passing, and a fork’s merge request is no longer shown for a same-named bookmark. Stacked pull requests target the repository’s default branch.
  • A change that only alters line endings shows its lines as changed, and a trailing-whitespace change highlights the whitespace.
  • Clean Up Stale Bookmarks keeps bookmarks that were never pushed and is a single undoable operation.
  • The CLI installer only replaces or removes a jayjay link it installed.
  • Large repositories list bookmarks and resolve revsets faster, and long diffs scroll with less work.
