New

  • Repositories can now be pinned from the repository list, keeping persistent projects separate from recent history.
  • The repository title now opens a menu for switching between open windows, reopening pinned repositories, returning to the repository list, or opening another repository.

Fixes

  • Review-note context can now be selected and copied across multiple lines.
  • Pinned repositories stay synchronized across running JayJay shells and remain accurate after storage resets or failed writes.
