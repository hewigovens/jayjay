Repository List

  • Recent Repositories now sit in a side panel beside the pinned list, so a long history no longer pushes pins below the fold. The panel opens with your first recent repository, closes when the last one is removed, and the sidebar button toggles it in between; the choice is remembered.
  • Pin or unpin a repository or workspace from the repository title menu, including the one you are working in.
  • Unpinning returns a repository to Recent instead of dropping it from the list.
  • The command palette gains a Repository List action.

Diffs

  • Drag the divider between two versions of an image to give either side more room; double-click it to reset.
  • Solidity files are highlighted again. The bundled grammar's query failed to compile, so they had rendered as plain text.
  • Expanding context in files without a grammar, such as lock files, CSV, and SVG, no longer builds highlight offsets it never uses.
  • Markdown previews keep a centered image centered when its wrapper spans several lines, and table headers render as a proper header row.
