Divergent changes

  • Resolve Divergent Change… in a divergent change’s menu opens a sheet that works like the merge editor. Keep A or Keep B takes one version whole, or decide the description, contents, author, and parents card by card, starting from the choices jj converge would make.
  • Each card shows what differs, including the file diff between the versions. Use A / Use B or Option-Left / Option-Right override a choice, and Edit… writes your own description. The sheet lists the descendants, bookmarks, and workspaces that will move, then converges in one undoable operation.

Keyboard shortcuts

  • A new Keyboard Shortcuts page in Settings lists every command with its shortcut. Search or show only modified ones, click a shortcut and press new keys to change it, and replace a conflicting shortcut or reset one or all.
  • Menus, the command palette, and the shortcut reference show your shortcuts.

Appearance

  • Built-in themes now color the whole repository window, not only diffs. Pick separate light and dark themes from Default, One, Gruvbox, Solarized, Catppuccin, Dracula, Nord, and Tokyo Night, with a preview of the window.
  • The graph draws immutable changes as diamonds, as jj log does.

Command line

  • jayjay import <URL> checks out a GitHub pull request or GitLab merge request into a new pr-<number> workspace.
  • jayjay workspace add <name> creates a sibling workspace on trunk(), and jayjay workspace prune deletes sibling workspaces whose changes have landed or are empty, keeping any with pending work.
