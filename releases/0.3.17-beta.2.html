Configuration that matches the jj CLI

  • JayJay now resolves jj configuration the way the command line does: conditional [[--scope]] tables, per-repository and per-workspace config, conf.d directories, system config, JJ_CONFIG, and the JJ_USER and JJ_EMAIL overrides all apply. A work email scoped to one repository now drives mine(), immutability, and the default revset there.
  • The embedded jj library is now 0.45.1. jj 0.45 records Git heads per workspace in the operation store, so keep the jj command line at 0.45 or newer for repositories you open in JayJay.

Faster history

  • Loading the graph, diffs, annotations, and Change Evolution no longer pays a per-commit cost on the app's worker threads, so large histories load several times faster.
  • The command line's default revset aliases such as trunk() load once per launch instead of failing to parse and spawning jj for every revset evaluation.

Fixes

  • Editing a change from the graph reseeds the commit box from that change instead of carrying over the previous working copy's draft.
  • Change Evolution remembers its pane widths across launches.
  • Absorb reports that there is nothing to absorb, and suggests Squash into parent, instead of appearing to do nothing.
  • Custom editor commands in Settings may include arguments, such as code --reuse-window.
  • A combined multi-change selection shows a stack icon in the compare banner; the reverse-direction control is reserved for two-revision comparisons.
