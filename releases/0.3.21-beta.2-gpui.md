### Colors, fonts, and settings

- Choose separate light and dark diff palettes in Appearance, with a live preview and matching editor and syntax colors. Built-in palettes include Catppuccin, Dracula, Gruvbox, Nord, One, Solarized, and Tokyo Night.
- Fonts now groups interface and code font families and sizes, code line spacing, ligatures, and a live preview. Reset Fonts restores both font configurations.
- Settings uses grouped rows and consistent icons with less explanatory text. Graph rows have tighter spacing that follows the selected fonts.

### Keyboard menus and editing

- Open the selected change or file’s context menu with the Menu key, Shift-F10, or Control-Return. Navigate with arrow keys or letter shortcuts; Escape returns to the pane.
- Keyboard focus returns to the repository window after a modal or editor closes.
- A line-number menu in either diff layout opens the working-copy editor or a supported external editor at that source line.

### Credits and fixes

- The change header credits co-authors from description trailers and a distinct committer, combining duplicate identities.
- Forgetting a Git-backed workspace releases its Git worktree registration so its path can be reused, while preserving checkout files unless Forget & Delete was selected.
