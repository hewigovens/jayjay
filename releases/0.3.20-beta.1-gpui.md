### New

- The GPUI shell leaves beta. On Arch Linux (x86_64 and aarch64), `curl -fsSL https://jayjay.hewig.dev/install.sh | bash -s -- --pacman-repo` trusts the signing key, adds the signed pacman repo, and installs; the guide keeps the reviewable manual steps.
- Rebase onto trunk in a change's menu, and Rebase Working Copy onto Trunk in the command palette, move a whole line of work onto trunk, including a workspace's working copy.
- Dragging a change that is part of a multi-selection rebases every selected change: the drop highlight, drag preview, and confirmation name the whole selection, and the confirmation is cancelled if any selected change moved meanwhile.
- Restore this version in the evolog context menu puts a previous version back into the working copy or the change the evolog was opened for, in one undoable operation; immutable changes are refused.
- The Recent panel in the repository list has a drag handle (220–560 px), gives way before the pinned column drops below its welcome width, and keeps its width in the layout config.

### Fixes

- Shared with macOS: repository actions run in-process through jj-lib instead of the `jj` binary, mutations from different windows and workspaces run one at a time so overlapping operations no longer leave a change divergent, undo snapshots pending edits first, colocated Git HEAD and branches update right after each action, and a rebase that moves nothing records no operation.
- Settings > Jujutsu reads the config files directly, works without the `jj` binary, groups values by section, and shows a load failure with the file that failed.
- The missing `user.name` / `user.email` alert now appears when jj has no identity configured.
