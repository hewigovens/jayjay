Change evolution viewer

  • Right-click any mutable change in the DAG and pick Show evolution… to see every prior version of that change with operation labels (snapshot, describe, rebase, squash, split, new) and timestamps.
  • Click an entry to interdiff that version against the current head; click a file to see the side-by-side diff using the same engine as the rest of the app.
  • Right-click a row for Copy Commit ID or Copy ‘jj restore’ command — useful for recovering work after a botched rewrite.

Pull Request creation

  • Right-click a non-trunk bookmark (in the DAG row or Bookmark Manager) and pick Pull Request on GitHub to open the existing PR if there is one, or GitHub’s compose URL otherwise. Driven by the gh CLI when present.

Command palette

  • jj is now a first-class prefix alongside !. Type jj st, jj log, jj fix and so on to run the raw CLI with inline output.

Polish

  • Annotate, File History, and Evolution panels share a consistent Done button and esc keyboard shortcut for closing.
  • The Evolution list uses the standard pane background instead of a sidebar vibrancy material that looked off in light mode.
  • Annotate header now shows Annotate: <path> for symmetry with the History panel.

Internal

  • Evolog and file annotate now run in-process via jj_lib::evolution and jj_lib::annotate — no jj CLI shell-out, no template parsing.
  • File history switched to a type-safe revset (RevsetExpression::filter + FilesetExpression::file_path) instead of formatted strings.
  • New DetailPaneMode enum collapses five mutually-exclusive view-state booleans into a single value; annotate and history loaders now guard against stale completions hijacking the pane.
