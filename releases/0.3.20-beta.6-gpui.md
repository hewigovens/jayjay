### Tags

- Create a lightweight tag from a change's context menu. The tag chip offers Push while the tag exists only locally, and Delete Tag on Remote once a tracked remote has it; that action asks for confirmation, removes the tag locally, pushes the deletion to every remote that tracks it, and restores the local tag if the push fails. Tags collapsed into the overflow chip keep their actions in the change menu.
- The revset bar gains a Tags preset for `tags()`, and Tab in the revset editor or popup finishes the highlighted completion, or the first one, instead of moving focus.

### Fixes

- CJK and other wide text: copying a diff selection after a wide glyph no longer takes the wrong text, review notes written in Chinese or Japanese wrap, and file paths, bookmark chips and context menus size wide glyphs as two columns.
- Input methods work in the diff find bar, the file filter, the bookmark picker and the repository switcher, and the candidate window for the commit editor follows the caret instead of landing at the bottom of the screen.
- The repository switcher and bookmark picker open under their toolbar buttons instead of at the click point.
- Opening a repository shows a spinner, and panes, pickers and diffs that wait for their first content share one loading indicator that names what is loading.
- Commits by coding agents such as Claude Code and GitHub Copilot show the account's GitHub avatar instead of a generated identicon.

### Performance

- The bookmark picker and repository switcher build only the rows in view. With about 800 bookmarks, opening the picker drops from roughly 610 ms to 78 ms and each frame with it open from 300 ms to 38 ms.
- The Repo Overview builds only the part of the canvas that is on screen, so tall overviews no longer lay out every lane on each frame.
