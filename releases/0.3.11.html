Improved

  • Send Feedback is available from the Help menu and the command palette, opening a pre-addressed email.

Fixes

  • Closing the only repository window after relaunching from the Dock now returns to the Repository List instead of leaving the window stuck in an unclosable state.
  • A minimized repository window is restored by Dock reopen again instead of being replaced by the Repository List.
  • Windows restored on a changed display arrangement are kept within the visible screen.
