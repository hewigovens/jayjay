## History navigation

- Follow the selected graph lane with j/k, Up/Down, or Ctrl-N/P, and switch columns with h/l or Left/Right. Tab and Shift-Tab move between panes. The selected lane stays emphasized while the file list has focus.
- Stacks stay together with the working copy’s first, and row dates use committer time.
- The default graph filter honors jj’s `revsets.log`; Default, Reset Filter, and an empty revset return to it.
- Use **Filter by This Bookmark** directly from a graph bookmark chip.
- The Repo Overview canvas accepts h/j/k/l as well as arrow keys.
- Search for **Show Evolution** in the command palette to inspect the selected change’s rewrite history.

## Diffs and repository setup

- Tabs display as four spaces and use four-cell wrapping and selection geometry, fixing missing indentation in Windows diffs.
- Large files with many scattered edits no longer overflow the diff engine’s stack.
- The conflict-resolution menu offers the merge editor configured in jj alongside JayJay and the selected external editor.
- Opening a subfolder resolves to its enclosing jj workspace. Git-only and empty folders offer jj setup; missing folders and failed initialization still show an error.
- Long setup paths fit within two lines, and long notification text wraps inside its bubble.

## Localization and maintenance

- Settings, menus, dialogs, shortcut guides, and diff tools now share a localization catalog. Choose System, English, or Japanese in Settings > Appearance; most text updates immediately.
- Updated runtime dependencies with upstream security fixes.
