Review

  • Clicking a file’s review mark, or the new Mark Reviewed button in the diff header, moves on to the next file like Space. The next file is the next unreviewed one after the current file, so files you skipped stay behind.
  • SVG and SARIF files open rendered, and their preview button returns to the source. Notebooks open as a text diff of their Markdown, with Preview and Source buttons beside it.
  • Pull request descriptions keep GitHub’s formatting tags, such as collapsible sections, tables, and lists, so release notes from Dependabot read as they do on GitHub.

Gerrit

  • Changes on a Gerrit remote get Upload to Gerrit in the change menu. After a change is submitted, Pull abandons the empty local copy it leaves behind.
  • An upload that would replace a newer patch set made in Gerrit is refused, and Update from Gerrit brings that patch set into your local change.
  • jayjay.upload-command and jayjay.sync-command let a repository replace Upload and Pull with its own jj commands.

Sync and Git

  • Pull, push, and bookmark tracking follow git.push, or the only remote, instead of assuming origin.
  • Built on jj 0.47.1. In colocated repositories, describing or rewriting the working-copy change no longer resets the Git staging area.

Settings and SSH

  • A new Flock page in Settings lets GitHub sponsors unlock a keepsake feather and extra light and dark Dock icons, also shown in About.
  • Reopening a remote repository whose checkout was deleted on the host reports it missing instead of opening and then vanishing, and a canceled request to a host that stopped answering disconnects instead of waiting.
  • The app bundles the license notices of its third-party components.
