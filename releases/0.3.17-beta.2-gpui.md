### New

- Linux defaults to the system editor and terminal: `$VISUAL` or `$EDITOR` with an `xdg-open` fallback, terminal editors such as vim, nvim, nano, helix, and `emacs -nw` open inside the terminal, and the default terminal honors `$TERMINAL`, then `xdg-terminal-exec`, then `x-terminal-emulator` and `xterm`.
- Custom editor and terminal commands are editable in Settings > Tools and accept arguments, such as `code --reuse-window` or `foot --title JayJay`.
- Open Repository falls back to a typed-path window when the desktop file picker is unavailable, for example without an XDG desktop portal.
- A fetch or push that finishes while the repository window is not active posts a desktop notification with its result.
- An Arch Linux package definition (`jayjay-appimage`, in `dist/arch`) wraps the AppImage; AUR publication follows once a release's AppImages are attached.

### Fixes

- jj configuration resolves like the command line: conditional `[[--scope]]` tables, repository and workspace config, `conf.d`, `JJ_CONFIG`, and the `JJ_USER`/`JJ_EMAIL` overrides apply, so `mine()`, immutability, and the default revset follow scoped identities.
- Graph, diff, annotate, and evolog loading no longer pay a per-commit cost, and the command line's default revset aliases load once per process.
- Absorb with nothing to move says so instead of appearing to do nothing.
- The embedded jj library is 0.45.1; keep the jj command line at 0.45 or newer alongside it.
