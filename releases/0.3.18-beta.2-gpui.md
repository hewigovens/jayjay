### New

- Tab and Shift-Tab cycle keyboard focus through the visible panes, controls, and text inputs. The focused control draws an accent ring, the active pane's selection stands out, Space or Return activates, and Escape releases focus. Find, overlays, and the file and revset filters keep their own keys.
- Agent review marks: `jayjay review status`, `mark`, and `unmark` let an agent pre-mark mechanical files or single change groups of the working copy, tied to the commit it inspected. Files with agent marks show an `agent` badge and count in the reviewed tooltip; an agent never takes over a group a person reviewed, and `unmark` drops only agent marks. `jayjay review --help` prints usage for every subcommand.
- Settings uses the same seven pages as macOS with a sidebar: Appearance, Diff & Files, Workflow, Integrations, Jujutsu, Data & Privacy, and About. Integrations holds the editor and terminal choices, codex and claude, the jj and forge CLIs, and the Linux `jayjay` install.
- Auto-expand descriptions (Diff & Files, off by default) opens an overflowing description at its expanded height as soon as a change is selected; the command palette toggles it too. The Forget & Delete workspace confirmation gains Don't ask again, restored from Workflow. Jujutsu reads Config not found or jj is not installed instead of a path to a missing file.

### Fixes

- A reviewed hunk's gutter stripe uses the accent color, matching macOS, instead of the added-file green.
- Every window shows readable jj and git errors: evolog, Bookmark Manager, file history, the operation log, context expansion, sync, bookmark and workspace toasts, the conflict editor, and the stacked-PR panel no longer print the raw command-failed chain. Palette `jj` and `!` output stays raw on purpose.
- Load more works after typing a custom default revset with a different depth.
- Bookmark comparisons are labeled PR Diff, and reversing one keeps the displayed file while flipping the direction.
- A jj operation the window is already at no longer forces a full graph reload.
- Shared with macOS: collapsed diffs are highlighted from the whole file, word-level marks are skipped on rewritten lines, status-bar totals match the detail header, context expansion no longer errors on an already revealed region, and LFS classification refreshes with `.gitattributes`.
