Fonts

  • Interface and code fonts are now separate. Appearance sets the interface font family and size; a new Code Font page sets the code font, size, line spacing and ligatures, with a live preview drawn by the real diff view and a reset that leaves the interface font alone. Existing settings carry over as the code font.
  • The code font picker lists System, then installed Coding Fonts, then Other Monospaced families, including Nerd Font patches and fonts installed by a package manager. The ligatures switch is disabled for fonts that have none.
  • Changing the code font, size or line spacing keeps the editor on the same line instead of jumping.
  • Zoom In, Zoom Out and Reset Zoom move to the View menu and change both font sizes; Appearance names their shortcuts.

Diffs and review

  • Right-click a line number in the unified diff and choose Edit File at Line N to open the working-copy file in the built-in editor with the caret on that line.
  • Renames come from jj's copy records, so a new file is no longer shown as a move of an unrelated file with the same name. Copies show as Copied and diff against their source, and split, move and restore on a rename act on the whole move.
  • File status badges use icons: ± for modified and a copy icon for copied.
  • The file list keeps the selected file in view when you move with j/k, the arrow keys or Space, and after a refresh. In tree view, keyboard navigation follows the order on screen and skips collapsed folders.

Revsets and workspaces

  • Recent revsets are saved per repository, shared by all its workspaces, and kept after the window closes, up to 15. Each entry in the revset panel's Recent section has a button that removes it.
  • Show one workspace's history: workspace names complete as name@ in the revset bar, and a workspace chip's menu offers Filter by This Workspace.

Fixes

  • Creating a bookmark or tag with a name git can't store is refused up front instead of failing later.
  • Comparing against a bookmark that exists only on a remote works again.
  • Git LFS files with spaces or non-ASCII characters in their names are recognized, so Hide Git LFS-backed files applies to them.
  • Graph bookmark and tag chips are slightly larger.
  • Onboarding's last page includes the anonymous usage statistics checkbox, and no statistics are sent before onboarding finishes.
