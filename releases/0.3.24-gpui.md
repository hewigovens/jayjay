## Fixes

- JayJay no longer fails to launch on Linux when fontconfig lists a font without an index. On affected systems, such as some Pop!_OS installs, the app exited before showing a window.
- A font that cannot be loaded is skipped in the **Settings → Fonts** lists, and a glyph that cannot be drawn in a text field no longer closes the app.
- Pull request and stacked pull request actions are offered only when the origin is a supported forge, and the Bookmark Manager follows a changed remote without reopening.
- Opening a self-hosted remote in the browser keeps its HTTP or HTTPS scheme and explicit port, and handles IPv6 hosts.
