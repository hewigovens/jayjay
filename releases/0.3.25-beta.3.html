Commit part of the working copy

  • Open Edit Diff, check the lines you want to commit, add a description, and choose Commit Selected. The checked lines become a new parent change. The remaining edits stay in your working copy.
  • If the working copy moves while the editor is open, JayJay asks you to select it again. With whitespace ignored, whitespace-only changes in surrounding lines stay out of the selected change.

Read stacked diffs

  • Fold individual files in a stacked diff to focus on the ones you are reading. Folded files stay folded when the selected change is rewritten. Large diffs and unavailable previews take up a single compact row.
  • The description editor opens larger and can be resized. Toolbar hints appear after one second, and the sidebar hint appears over its own button.
