### Windows and Linux improvements

- GPUI resolves fonts when font preferences change and builds the Settings font catalog in the background, reducing pauses when opening repositories and font menus.
- Workspace picker rows and graph chips offer **Filter by This Workspace**. **Show in File Manager** is available from the Repository menu with Ctrl+Alt+F on Windows and Linux.
- **Help → Reveal Logs** opens the shared local log. **Debug mode** in **Settings → Data & Privacy** adds snapshot and graph timings and monitors main-thread stalls throughout the session. It defaults to on in beta builds unless you have saved a preference; Send Feedback reveals the log for you to attach.
- Syntax highlighting adds PowerShell, Batch, INI, CMake, and XML-family files. The repository list uses a clearer sidebar toggle icon.
- Updated GPUI and Rust dependencies include security and compatibility fixes.

### Windows installation

JayJay is now listed in the [Microsoft Store](https://apps.microsoft.com/detail/9pjrq1hg25vb). Use the portable Windows x64 ZIP attached to this GitHub prerelease to try this beta. Store updates are submitted separately for stable releases. Install `jj` separately on PATH for either distribution.
