New

  • Rich diff previews for Markdown, notebooks, CSV/TSV tables, binary property lists, and SARIF reports.
  • Text-backed formats still open as raw diffs by default, with a preview button when a richer view is available.
  • Working-copy HTML files can open in the default app from the diff header, so linked CSS and images work normally.
  • Changed-line diffs now highlight the smallest changed text with subtler word backgrounds.

Fixes

  • Repository initialization now shows the underlying jj git init error and hint instead of a generic failure.
  • Show in Finder from the file list context menu now reveals the selected file reliably.
  • Switching rich previews no longer flashes through the processed text view.

Under the Hood

  • Diff projection, source-preview, and external-preview behavior is documented and covered by shared CSV, notebook, property list, Markdown, HTML, and SARIF fixtures.
