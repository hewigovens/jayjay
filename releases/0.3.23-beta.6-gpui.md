## Review

- In the tree file list, right-clicking a folder marks the files listed under it as reviewed, or unreviewed when they all are.

## Diffs

- A changed `.zip`, `.jar`, `.aar`, `.apk` or similar archive shows one line per file with its checksum, size and path instead of a binary placeholder. Nothing is decompressed.
- A notebook, table or other structured file whose other side cannot be read, such as one over the size limit, keeps that side's placeholder instead of looking deleted.

## Fixes

- Undo no longer reverts a working-copy snapshot, which deleted the edits the snapshot had recorded from disk; it now says why it did nothing. Deleting a file or ignoring one from the app stays undoable.
- The detail pane stays steady across background refreshes: a change that is already shown keeps its files and diff, a rewritten change reloads in place instead of blanking first, a compare or multi-selection whose changes are unchanged is kept, and automatic refreshes no longer show the toolbar indicator.
- The command palette lists help topics in their own **Help** section after every other match, and its shortcut focuses the open palette instead of opening a second one.
- The rating prompt does not appear in response to undo or redo.
- On Windows, jj on the user PATH, as Scoop installs it, is found when a launcher such as PowerToys Run starts JayJay with only the system PATH.
