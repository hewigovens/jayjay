Review

  • In the tree file list, right-clicking a folder offers Mark N Files as Reviewed for the files listed under it, or Unreviewed when they all are.

Diffs

  • A changed .zip, .jar, .aar, .apk or similar archive shows one line per file with its checksum, size and path instead of a binary placeholder. Nothing is decompressed.
  • A notebook, table or other structured file whose other side cannot be read, such as one over the size limit, keeps that side’s placeholder instead of looking deleted.

Fixes

  • Undo no longer reverts a working-copy snapshot, which deleted the edits the snapshot had recorded from disk. Deleting a file or ignoring one from the app stays undoable.
  • The detail pane stays steady across background refreshes: an unchanged change is no longer rebuilt, a compare or multi-selection whose changes are unchanged is kept, the toolbar spinner stays off, and the pull request badge updates without clearing first.
  • The command palette lists help topics in their own Help section after every other match.
  • The rating prompt does not appear in response to undo or redo.
