Diffs and previews

  • Lua files are highlighted, and a script with no file extension, such as bin/tool, is highlighted by the interpreter named on its #! line.
  • A file that fails to load in Diff Edit shows the error with Retry instead of an empty card.
  • A previewed HTML file that declares no character set is read as UTF-8, so symbols such as ⌘ no longer appear garbled.

Terminal

  • With Rex as the terminal, a command such as a terminal editor opens in a new Rex tab instead of falling back to Terminal, including when Rex has to start first.

Fixes

  • With unsaved edits in the working copy, squashing into a chosen change, creating a workspace on a revision, applying a merge editor result to a change other than @, and Bisect Between now act on the current version of the change. Before, they could leave a divergent copy behind, and the bisect stopped before its first step.
  • Squashing a change into itself does nothing instead of rewriting it with a doubled description.
  • The letter on an author’s placeholder avatar comes from the author’s name instead of the email address.
