### New

- Run formatters (jj fix) on a change, a multi-selection, or from the command palette runs the tools in your `[fix.tools]` config over the selected changes and their descendants with jj's semantics. A failing tool leaves its file unchanged and is reported, an immutable change is refused before anything runs, and an unusable config disables the menu items with the reason.
- Merge N selected opens a First parent submenu so you choose which selected change leads the merge.
- New Workspace from Pull Request also imports GitLab merge requests, signing in through `glab` when it is installed or a `GITLAB_TOKEN` otherwise.
- After the fifth successful action, then every twentieth, a rating prompt asks for a GitHub star, with Sponsor beside it and Don't show again below. Its state lives in `rating_prompt.json`, so routine actions never rewrite `config.toml`.
