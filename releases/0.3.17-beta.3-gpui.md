### New

- Hunk review: click a gutter stripe in the unified or side-by-side diff to mark that change group reviewed. File rows roll up unreviewed, partial, reviewed, and changed-since-review state, and marks follow hunks across edits like the macOS app.
- The interface font-size setting scales the repository window, Settings, Change Evolution, and the Bookmark Manager.
- The bookmark picker has a Remote Only section for browsing a remote's history without tracking it; Pull and Push no longer track remote bookmarks automatically.
- Launching without a repository path opens the workspace that contains the current directory, then the most recent valid workspace, and otherwise the repository list. First-run onboarding appears with the list.
- Submodule and other non-text conflicts show the conflict banner with Use Ours and Use Theirs; Edit in JayJay stays limited to text conflicts, and conflicted files are not offered to the file editor.
- Arch Linux: every release attaches a `jayjay-appimage` package (`.pkg.tar.zst`) for x86_64 and aarch64. Install a beta with `pacman -U`; stable releases are also published to a pacman repository.
- The AppImage is built against glibc 2.31, so it runs on Debian 11 and Raspberry Pi OS bullseye.

### Fixes

- Clicking an item in the in-window menu bar runs its action; before, only the keyboard shortcut did.
- Every window carries the app id `dev.hewig.JayJay`, so Wayland compositors and taskbars match it to the desktop entry.
- The system editor runs terminal editors and `$EDITOR` wrappers inside the configured terminal, and without `$VISUAL`/`$EDITOR` it uses the desktop's default text editor. Menus name the choices System Editor and System Terminal.
- External editors, terminals, browsers, and opened links no longer write into the terminal JayJay was started from.
- When none of the preferred monospace families is installed, the diff font resolves through fontconfig instead of falling back to the proportional UI font, which closes the gap before the copy button.
- Shared with macOS: merge lane drawing, missing-ancestry caps, unified-diff grouping of removed and added lines, and large-repository responsiveness.
