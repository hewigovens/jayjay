Operation Log

  • The Operation Log opens as a resizable pane at the window’s trailing edge instead of a sheet. Show or hide it with its toolbar button, View → Show Operation Log (⇧⌘U), the last operation in the status bar, or the command palette. JayJay remembers whether it is open.
  • While the pane is open, its toolbar button sits at the pane’s leading edge and the revset field narrows to make room. In a narrow window the pane gives up width so the sidebar, file list and diff keep their minimum sizes; widening the window restores the width you dragged it to.
  • Restore an operation from its row’s context menu, ⌃Return, Edit → Restore Selected Operation, or the command palette. A refresh keeps the selected operation.
  • When the operation history cannot be read, the pane shows the error instead of No operations found. When the revset stops evaluating, the operation list and status bar still show the operation that broke it.

Toolbar and layout

  • The sidebar toggle has its own capsule. Refresh, pull and push sit in a second capsule that narrows away when the sidebar hides and returns with it.
  • Pull and push use a matching pair of tray icons, and review mode uses a list-with-checkmark icon so it no longer looks like a reviewed file’s mark.
  • The toolbar no longer has Settings or Show in Finder buttons; both remain in the menus and the command palette. Editor and terminal buttons show the configured app’s icon.
  • Double-clicking empty space between toolbar items acts like double-clicking the title bar, following your setting in System Settings.
  • The repository title is larger and lines up with the change title. It no longer shifts while the sidebar animates or when switching between workspaces with names of different lengths.
  • The change header, with its title, byline, description and divergence and stale-note bars, now spans the file list and the diff. Details stay collapsed by default.
  • Panes are separated by a hairline that runs up through the toolbar.
  • View → Hide Status Bar and Hide / Show Status Bar in the command palette hide the status bar.

Changes and commits

  • The commit box in the sidebar appears only while the working copy has no description or holds an unsaved draft. Once a draft is saved, the space goes back to the change list.
  • A described working copy is edited from its change header. Its Edit Description sheet offers Save, Commit and message generation, and stays open if the commit fails.
  • A described working copy’s change menu and the command palette offer Commit, which commits an unsaved draft that has a summary, or otherwise the saved description.
  • The change header shows the commit ID beside the change ID, each with its unique prefix highlighted and a copy button. In a narrow pane the date drops first, then the commit ID.
  • The change list header shows how many changes are divergent or conflicted, moved from the status bar. Click a count to filter to divergent() or conflicts().
  • Change ID prefixes and bookmarks are magenta and commit ID prefixes are blue, as in jj log.

Files and diffs

  • File rows show the containing folder under the file name, in the flat list and the tree alike. Files at the repository root have no second line, and moves still show their full source and destination.
  • An empty change shows No Files Changed once across the detail pane, with the file list hidden until the change has files.
  • When a change has files but none are listed, the detail pane says why — no filter match, all files reviewed and hidden, no files with review notes, or Git LFS and submodule files hidden by settings — and ends with a link that undoes it, such as Clear Filter or Show Reviewed Files.
  • With the file list focused, Page Up, Page Down, Home and End scroll the diff.
  • Syntax colors stay distinct from one another in low-contrast themes.

Review

  • A mutable change other than the working copy has its own review mode, turned on from the file list header, Repository → Review Mode, or Toggle Review Mode in the command palette. It starts on when the change already has review marks or notes, and off otherwise.
  • With review mode off, file rows show the change-type badge instead of review marks, the header shows the plain file count, and Mark Reviewed, Space marking and hiding reviewed files are off. Review notes still show. With it on, the header count shows review progress.

Git submodules

  • JayJay no longer manages Git submodules when you commit. The Submodule changes need attention sheet and the automatic submodule commit are gone, and Commit and Describe work in a repository with dirty submodules like any other.
  • A submodule with uncommitted edits no longer gets its own row in the working copy. A submodule’s diff shows only which commit it points to.
  • Enable Git submodule support in Workflow settings is now Show Git submodule changes under Git LFS and Submodules in Diff settings, and only controls whether submodule changes are listed. Your existing choice carries over.

Pull, push and remote repositories

  • A failed pull shows Git’s own output instead of only “External git program failed”.
  • Push says plainly when there is nothing to push, for example when no bookmark is ahead of the remote.
  • A disconnected SSH repository shows a bar with Reconnect above its content. Reconnect is also in the Repository menu and the command palette.

AppleScript

  • JayJay has a scripting dictionary. Scripts can open a repository, address it by its workspace root, read and set its revset, refresh it, select a change, show one of its files, and read the selection, the window ID and any error or notice on screen.
  • Each command returns once the window has settled, so scripts need no delays. The front repository falls back to a hidden or minimized window when no repository window is visible.

Fixes

  • Launching JayJay with a repository path as its argument opens that repository.
  • A long rename in the file list keeps its arrow and destination visible.
  • The keyboard-selected file stays in view in long file lists during fast key repeat.
  • Picker panels, such as the repository and bookmark pickers, no longer show a scrollbar.
