Bookmark diffs

  • SwiftUI can now diff bookmark ranges from the DAG context menu and Bookmark Manager, showing the full change range from the fork point to the selected bookmark instead of only an interdiff between two revisions.
  • Bookmark revsets are quoted and displayed consistently, including names that need escaping, and compare direction keeps its title and labels when reversed.

Command palette jj commands

  • Run raw jj commands from the command palette with argument parsing, in-memory history, command output, and a copy-output action.
  • Successful raw commands refresh the repository view so quick status, log, diff, and operation-log checks can stay inside JayJay.

Find and revset fixes

  • Diff find now highlights visible matches immediately, distinguishes the current match, searches across side-by-side panes, and clears highlights when the native find bar closes.
  • Revset parsing now loads jj's default revset aliases through the CLI, so user config that references aliases such as builtin_immutable_heads() works in JayJay too. Fixes #60.

Internal

  • Split repository resolution into focused modules, model change authors with a shared CommitAuthor value, and removed obsolete agent config files from the codebase.
