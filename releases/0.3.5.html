New

  • Local review notes let humans and coding agents leave, edit, and resolve line-anchored comments on changed files without leaving JayJay.
  • Notes show in the diff gutter, inline diff text, file list badges, and the change review summary.
  • The jayjay review CLI command reads and writes the same local review store, so agents can exchange review context with the app.

Under the Hood

  • Review marks and notes now use a shared Rust store across SwiftUI, GPUI, and CLI surfaces, with atomic writes and corrupt-file preservation.
