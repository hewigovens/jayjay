This release rolls up nine betas.

- **Keyboard history navigation**: follow a graph lane with j/k, switch columns with h/l, and open any context menu with Control-Return.
- **Bisect**: mark changes Good, Bad, or Skip, or let a test command find the first bad change.
- **Better diffs**: moved-code links, file-type icons, offline Mermaid previews, and copy that keeps source lines intact.
- **Make it yours**: light and dark diff palettes, separate interface and code fonts, and Japanese, Simplified Chinese, and Traditional Chinese.
- **Forges and agents**: sign in to GitHub and GitLab from Settings, stack PRs on Codeberg, and install the JayJay skill for Claude Code, Codex, and Cursor.
- **Linux and Windows**: Debian packages, and JayJay is now in the Microsoft Store.
