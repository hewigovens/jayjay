Workspaces without losing context

  • Click the repository title to search and switch between the current repository's workspaces, other open windows, pinned repositories, and recent repositories; refresh workspace state directly in the picker.
  • Workspace rows show the working-copy change, description, conflicts, age, and changed-file count. The Repository List now groups recent sibling workspaces beneath their primary repository.
  • Forget keeps the checkout on disk, while Forget & Delete closes matching windows and removes only the verified checkout after jj forgets it.

Cursor Origin and CLI settings

  • Open or create Cursor Origin pull requests with the authenticated origin CLI, including one dependent pull request per change from the stacked-PR workflow.
  • Settings now groups version-control and forge CLIs (jayjay, jj, gh, glab, and origin) in a dedicated CLI tab.

Fixes

  • Dragging the working-copy @ chip over an immutable change now gives a terse refusal and cancels quietly; dropping a change onto its only parent no longer creates a no-op rewrite.
  • Removing a conflicted bookmark from one DAG change keeps its other targets intact.
  • Deeply nested property lists fall back to the raw view instead of overflowing the parser stack, and jj-lib futures get enough stack when mutations run from macOS worker threads.
  • Workspace removal waits for repository work, handles path aliases, restores the window when forgetting fails, and cannot delete an unrelated directory that replaced the selected checkout path.
