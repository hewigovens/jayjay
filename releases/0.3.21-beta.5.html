Sign in from Settings

  • Connect GitHub and GitLab from Settings → Integrations with a browser code. Existing CLI logins and environment tokens still work, and Sign Out removes the login stored by JayJay.
  • Cursor Origin pull requests and stacked PRs use its API directly with your existing Origin login. Codeberg also recognizes tea logins.

Compare revisions and preview diagrams

  • Two selected revisions now compare their endpoint trees when they cannot form a combined diff, including sibling changes and merges.
  • Mermaid previews use a shared offline renderer. Unsupported or oversized diagrams remain readable as source, and Markdown previews support pinch zoom.
  • Modified and copied file badges have clearer symbols.
