### Forge sign-in

- Sign in to GitHub and GitLab from Settings using a browser code, or keep using environment tokens and existing CLI logins. Sign Out removes the sign-in stored by JayJay.
- Cursor Origin PRs and stacks use its API with your Origin login. Codeberg also accepts tea logins.

### Diffs and layout

- Render Mermaid diagrams offline in Markdown previews, with source fallback for unsupported or oversized diagrams.
- Compare endpoint trees when two selected revisions cannot form a combined diff, including siblings and merges.
- Resize the Settings sidebar and use wider pane handles that keep the resize cursor while dragging.
- Octicons and redrawn file-status badges make graph, file, and Settings icons more consistent.

### Linux installation

- The one-line installer uses Debian packages on apt-based systems and AppImages elsewhere. Add `--beta` for the latest beta ahead of stable; Arch uses the signed pacman package.
