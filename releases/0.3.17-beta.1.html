Review and reshape changes together

  • Shift-click changes in the graph to inspect a consecutive stack as one diff, then merge independent heads, squash a linear range, abandon mutable selections, or rebase the selected changes onto another revision while preserving their dependencies.
  • Create a new change directly before or after a revision when the graph topology permits it.
  • Review marks now follow individual hunks across edits and rebases. File rows show partial and changed-since-review state, and Settings can clear all stored review marks and notes.

Quieter history and refreshes

  • Change Evolution collapses consecutive working-copy snapshots, can hide snapshots entirely, and compares any two selected versions with rename-aware diffs.
  • External file and jj changes update the visible working copy automatically, while editors, review-note composers, and confirmation sheets keep unfinished input safe.
  • Moving through changes keeps the previous detail visible until the next selection is ready instead of flashing a loading placeholder.

Workflow polish

  • Workspace menus can copy the workspace name directly as well as its path.
  • Fetch and push actions can be canceled even when a credential helper outlives jj, and JayJay terminates its remaining jj subprocesses when the app quits.
  • Repositories still open when the global Git config contains conflict markers, and avatar caches now use the native macOS cache directory.

Fixes

  • Multi-change selections stay attached to the intended revisions through working-copy snapshots, divergent changes, batch rewrites, and refreshes.
  • Combined diffs require a truly consecutive direct-parent chain, and batch squash selects the exact rewritten destination even when the result is divergent.
  • The built-in jayjay command parser now accepts option values that begin with a dash and handles -- and short-option = syntax consistently.
