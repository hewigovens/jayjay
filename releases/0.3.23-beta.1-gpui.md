## Remote repositories over SSH

- Open a jj repository on another machine from **Open Remote Repository** in the File menu or the command palette, with host suggestions from your SSH config and remote folder browsing.
- The status bar shows the host and its connection state; its connection window disconnects and reconnects. The repository dims while disconnected, and a write is never retried on its own.
- On Linux, JayJay connects to macOS, Linux, and Windows hosts; on first connect it downloads the small helper it runs on that host and checks it against this release. Review notes stay on your machine. Remote repositories on the Windows build follow in a later release.

## Menus and windows

- Menu bar menus open under their title, switch on hover or with Left and Right, show their keyboard shortcuts, and move with Up, Down, and Enter.
- On Windows, the title bar icon opens the system menu.
- Diff text keeps clear of the conflict stripe.

## History and safety

- A workspace chip’s menu in the graph offers **Rebase Lane onto _trunk_**.
- File deletions and ignore-file additions stay inside the repository even through symbolic links, and SVG previews render as inert images.
