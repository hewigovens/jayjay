History navigation

  • Follow the selected graph lane with j/k, Up/Down, or Ctrl-N/P, and switch columns with h/l or Left/Right. Tab and Shift-Tab move between panes. The selected lane stands out while other graph lines fade, even while the file list has focus.
  • Stacks stay together with the working copy’s stack first, and row dates use the committer time so rebased work shows its latest rewrite.
  • The default graph filter follows your jj revsets.log setting. Default, Reset Filter, and an empty revset return to it.
  • Filter directly from a graph bookmark chip with Filter by This Bookmark.
  • Search for Show Evolution in the command palette to inspect the selected change’s rewrite history.

Diffs and repository opening

  • Opening a subfolder now opens its enclosing jj workspace, including through the CLI launcher.
  • Tabs count as four visual cells when wrapping and selecting diff text.
  • The pane-divider grip remains easy to grab from the diff side.
  • The conflict banner offers your jj-configured merge editor alongside Edit in JayJay and the external editor selected in Settings.
  • Large files with many scattered edits no longer overflow the diff engine’s stack.

Localization and maintenance

  • Settings, menus, dialogs, shortcut guides, and diff tools now share a localization catalog. Choose System, English, or Japanese in Settings > Appearance. Most text updates immediately; use Relaunch to update macOS system menus and update dialogs.
  • Updated runtime dependencies with upstream security fixes.

Terminal integration

  • Choose Rex in Settings > Integrations to open repository folders in Rex Beta. Terminal-editor commands continue to use Terminal.
