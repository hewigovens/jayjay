### New

- Install or upgrade with one command: `curl -fsSL https://jayjay.hewig.dev/install.sh | bash` places the AppImage for x86_64 or aarch64 under `~/.local` with a `jayjay` command and a desktop entry after verifying its checksum. Arch Linux gets a `jayjay-appimage` package (`.pkg.tar.zst`) for both architectures on every release; stable releases are signed and published to a pacman repository.
- The AppImage is built against glibc 2.31, so it runs on Debian 11 and Raspberry Pi OS bullseye. Launching from a terminal detaches the app; `jayjay --foreground` keeps it attached, and `--help`, `--version`, and `--repo` are available.
- Linux defaults to the system editor and terminal: `$VISUAL` or `$EDITOR` with an `xdg-open` fallback, terminal editors such as vim, nvim, nano, helix, and `emacs -nw` open inside the terminal, and the default terminal honors `$TERMINAL`, then `xdg-terminal-exec`, then `x-terminal-emulator` and `xterm`. Custom editor and terminal commands are editable in Settings > Tools and accept arguments.
- Hunk review: click a gutter stripe in the unified or side-by-side diff to mark that change group reviewed. File rows roll up unreviewed, partial, reviewed, and changed-since-review state, and marks follow hunks across edits.
- Show ancestors… from a change's menu filters the graph to everything that leads to it, with Back in the revset filter to return. Right-click a workspace's `name@` chip to open it in a new window or copy its name or path.
- Recent Repositories sit in a side panel beside the pinned list, pin or unpin a repository or workspace from the title picker, and the command palette gains a Repository List action. Open Repository falls back to a typed-path window when the desktop file picker is unavailable, and a pathless launch opens the workspace containing the current directory, then the most recent one, then the list.
- Markdown previews render images inline (checkout-relative paths, `data:` URIs, SVG), image comparisons have a draggable divider, the interface font-size setting scales every window, and the light theme moves to neutral grays with hairline borders.
- The bookmark picker has a Remote Only section for browsing a remote's history without tracking it; Pull and Push no longer track remote bookmarks automatically. A fetch or push that finishes while the window is not active posts a desktop notification.
- Submodule and other non-text conflicts show the conflict banner with Use Ours and Use Theirs.

### Fixes

- jj configuration resolves like the command line (conditional `[[--scope]]` tables, repository and workspace config, `conf.d`, `JJ_CONFIG`, `JJ_USER`/`JJ_EMAIL`), and the embedded jj library is 0.45.1; keep the jj command line at 0.45 or newer.
- Clicking an item in the in-window menu bar runs its action, every window carries the app id `dev.hewig.JayJay` for Wayland compositors and taskbars, and external editors, terminals, and browsers no longer write into the terminal JayJay was started from.
- When none of the preferred monospace families is installed, the diff font resolves through fontconfig instead of the proportional UI font.
- Editing the Recent list no longer flashes nested workspaces out and back in, and unpinning returns a repository to Recent.
- Shared with macOS: faster graph, diff, annotate, and evolog loading; large-repository responsiveness; merge lane drawing and missing-ancestry caps; unified-diff grouping of removed and added lines; Solidity highlighting; Markdown centered images and table headers; Absorb explains a no-op.
