Word-wrap for diff views

  • Long lines in unified and side-by-side diffs now wrap to multiple visual rows instead of hiding the tail behind a horizontal scrollbar. Continuation rows share the same line number as their first row (blank gutter on the wraps) so the eye stays oriented.
  • Side-by-side wraps to the tallest side and pads the shorter pane with empty continuation rows, so the two panes — and their gutters — advance in lock-step. No more visual desync when one side has a long Removed line opposite a short Added line.

Short context runs stay inline

  • The context collapser used to fold any run of unchanged lines longer than the visible context. It now keeps runs of 2 lines or fewer inline — a one-line "N unmodified lines" separator was uglier than just showing them.
  • Separator label rewording: "N hidden lines" → "N unmodified lines" — they're not hidden, they're just unchanged.

Revert correctness

  • Revert Change (from the DAG context menu or command palette) now lands the reverse change as a child of the working copy, matching jj revert --onto @. Previously the reverse change was inserted between the target and its parent, which surprised users coming from the CLI and could pull unrelated commits along for the ride.

Internal

  • Split jj-diff's wrap module into a folder mod with focused submodules (cols.rs, chunks.rs, unified.rs, side_by_side.rs, ...); updated AGENTS.md to prefer folder modules over single long-file modules.
  • The macOS app's CLI-path resolver now uses a thread-safe getpwuid_r, filters relative PATH entries, checks the exec bit, and falls back to $SHELL if no login shell is available.
