## Repository responsiveness

- Opening repositories stays responsive while filesystem monitoring starts in the background.
- Filesystem watchers no longer follow symlinks inside the checkout, avoiding repeated traversal of linked dependency trees such as pnpm's node_modules.

## Windows

- Window controls share the menu bar, with draggable title areas and minimize, maximize/restore, and close buttons.
- MSIX installations include default and light-theme taskbar icons so Windows displays the icon without an unwanted background plate.
- Portable archives use `JayJay-0.3.22-beta.2-windows-x64.zip`, dropping the `-alpha` filename suffix. Winget manifest metadata is corrected.
- Microsoft Store updates remain limited to stable releases; install this beta from its portable ZIP.
