## Remote repositories and history

- Open repositories on macOS, Linux, and Windows hosts over SSH, with host suggestions, remote folder browsing, verified helper downloads, and Disconnect/Reconnect controls. Review data stays on your machine; disconnected writes are never retried automatically.
- Resolve divergent changes from the change menu or detail header: keep one version or choose description, contents, author, and parents, preview the effects, and converge in one undoable operation.
- Merge two or more selected changes, including an ancestor and its descendants, with your choice of first parent. Rebase a workspace lane onto trunk from its graph chip.
- Undo and redo repository operations with **Ctrl+Z** and **Ctrl+Shift+Z**, plus **Ctrl+Y** on Windows. Text fields keep their own undo; history rewrites offer an Undo toast, and undo skips working-copy snapshots.

## Review and appearance

- Review any mutable change, mark a folder’s listed files together, and move to the next unreviewed file after marking a file or multi-selection. Settings can prune review data for changes that are no longer mutable.
- Render SVG and SARIF previews, read notebook Markdown diffs, and compare ZIP-family archives as file listings with checksums and sizes. Lua and extensionless scripts with a recognized shebang get highlighting.
- Customize shortcuts in **Settings → Keyboard Shortcuts**. Menus, the palette, and the shortcut reference follow your choices.
- Built-in themes color the whole window, immutable changes appear as diamonds, and the Flock settings page offers sponsors a keepsake feather and the About bird picker.

## Integrations and packages

- Upload to Gerrit, update from newer remote patch sets, and clean up submitted changes on Pull. Sync follows the configured remote; colocated Git staging is preserved with jj 0.47.1.
- Use `jayjay import <URL>`, `jayjay workspace add <name>`, and `jayjay workspace prune` to import pull or merge requests and manage sibling workspaces.
- Windows is now beta, with native ARM64 and x64 ZIP packages. Linux distribution includes AppImages and Debian packages; Arch users can use the independently maintained `jayjay-appimage` AUR package.

## Fixes

- Background refreshes preserve unchanged detail views and comparisons. Rapid saves and in-place Windows saves refresh reliably.
- Settings, Keyboard Shortcuts, Clone, and the command palette reuse their existing windows. Clipboard shortcuts work in inputs, and palette navigation keeps the selection visible.
- A malformed configuration value no longer resets all settings; the original configuration is backed up. Failed overview and annotation loads display errors.
- Scoop-installed jj launches through its resolved target and is found through the registry PATH when a launcher supplies only the system PATH.
- Snapshot rewrites are followed by squash, conflict application, and bisect; squashing into the same change does nothing. Bookmark operands, line-ending edits, structured-file placeholders, and file-operation confinement receive the same shared-core fixes as macOS.
