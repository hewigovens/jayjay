Read several files in one diff

  • Select several files to scroll through their diffs together, or press ⌘A in the file list to select them all. Enable Show all files’ diffs in one list in Diff settings to start with the whole change.
  • Stacked diffs support unified and side-by-side layouts. The current file’s header stays visible as you scroll. You can focus on one file and return to the full list, and collapsing a folder keeps its selected files in the preview.
  • The layout switch and Edit Diff are in the change header. In Edit Diff, use a gutter stripe or its menu to deselect a change group. Background rename detection now preserves your line selections.
  • A checkbox at the end of each file row shows its review state. Marking several files together saves their marks in one operation.

Working copies and history

  • Large changes show their file list while rename detection runs. Syntax highlighting now recognizes Dart, Dockerfile, Just, Protobuf and R, along with more extensionless scripts.
  • Working-copy snapshots respect snapshot.auto-track and snapshot.max-new-file-size. If an automatic snapshot fails, a notice tells you the view is out of date and clears after a successful snapshot.
  • When a snapshot or another workspace’s operation blocks Undo, ⌘Z explains why and offers to open the Operation Log. Undo is disabled while a repository action or refresh is in progress.
  • A pull request from the same repository uses its head bookmark to name the new workspace. Remote repository operations can find the macOS desktop SSH agent when you connect through SSH.
