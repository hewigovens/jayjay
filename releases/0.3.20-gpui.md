### New

- The GPUI shell leaves beta. On Arch Linux (x86_64 and aarch64), `curl -fsSL https://jayjay.hewig.dev/install.sh | bash -s -- --pacman-repo` trusts the signing key, adds the signed pacman repo, and installs; the guide keeps the reviewable manual steps.
- Repo Overview comes to Linux: Repository > Repo Overview (Ctrl+Shift+O), the command palette, or the Overview button in the workspace picker shows every lane of mutable work as a tree growing from trunk, with lane panels, filtering, keyboard navigation, and rebase, abandon, open, reveal, forget, and delete actions. Only the visible part of the canvas is built.
- The revset filter moves into the center of the title bar with in-place editing, a presets popup that now includes Tags, recent revsets, and completion of revset functions, aliases, and bookmark, remote, and tag names; Tab finishes the highlighted completion. The Bookmarks picker moves to the graph header.
- Choosing a workspace in the repository switcher or the palette's Switch to entries opens it in the current window once it has loaded, keeping unsaved commit-message drafts per workspace. New Workspace from Pull Request also imports GitLab merge requests.
- Rebase onto trunk, whole-selection drag rebase, Parallelize, Merge with a chosen First parent, Restore this version in the evolog, and Run formatters (jj fix) over `[fix.tools]`.
- Create a lightweight tag from a change's menu; the tag chip pushes a local-only tag and offers Delete Tag on Remote once a tracked remote has it.
- `h` and `l` work like Left and Right for moving between the graph and file list and for collapsing Diff Edit cards.
- After the fifth successful action, then every twentieth, a rating prompt asks for a GitHub star, with Sponsor beside it and Don't show again below.

### Fixes

- Shared with macOS: repository actions run in-process through jj-lib 0.46 instead of the `jj` binary, mutations from different windows and workspaces run one at a time, undo snapshots pending edits first, and colocated Git HEAD and branches update right after each action.
- When another workspace rewrites this workspace's working-copy change, JayJay no longer snapshots the old files over the rewrite; the `@` row shows a warning glyph with Update Workspace, and Refresh updates it like `jj workspace update-stale`.
- After a fetch or pull, a bookmark whose remote branch was deleted once its pull request merged is cleaned up in one undoable operation.
- CJK and other wide text measure as two columns in diffs, notes, paths, chips and menus, and input methods work in the find bar, file filter, bookmark picker and repository switcher. The switcher and bookmark picker open under their toolbar buttons.
- The AppImage bundles the keyboard libraries it links and leaves glibc and the GPU and display stack to the host, so it starts on systems without libxkbcommon-x11; on aarch64 it loads on 16K- and 64K-page kernels.
- The Keyboard Shortcuts window and hints read their keys from the active keymap, so Linux shows Ctrl and Alt.
- Fish scripts get syntax highlighting, and commits by coding agents such as Claude Code show the account's GitHub avatar.

### Performance

- Refreshing the graph after a snapshot is about four times faster in large repositories, diff line wrapping is about ten times faster, and the bookmark picker and repository switcher build only the rows in view.
