### New

- The revset filter moves into the center of the title bar with in-place editing: click it, use Repository > Filter by Revset, or the palette; the filter icon opens presets, the current revset, matching bookmarks, and recent revsets, and a suggestions popup completes revset functions, aliases, and bookmark, remote, and tag names at the caret (Down picks, Return inserts).
- The Bookmarks picker moves to the graph header beside the change count. Clicking or entering a bookmark selects its exact commit; Filter by This Bookmark narrows the graph to the bookmark and its changes over trunk.
- Choosing a workspace in the repository switcher, or the palette's new Switch to entries, opens it in the current window, or activates the window that already shows it. The destination loads before the window changes, so a failed open keeps the source usable; unsaved commit-message drafts are kept per workspace across switches; a window's overview, bookmark manager, evolog, file history, and operation log close when it switches. Alt-click or Open in New Window still opens a separate window.
- Parallelize a connected run of selected changes into siblings from the multi-selection context menu or the palette.
- The diff header shows the status pill and line counts by the file name, with Preview, the view-mode toggle, Edit Diff, and Edit File in one labelled style on the right that drops to icons in a narrow pane; Tab reaches Edit File after Edit Diff. The file column header puts its controls first and one count last, and a short description body fits its text.

### Fixes

- The AppImage bundles the keyboard libraries it links (libxkbcommon, libxkbcommon-x11, libxcb-xkb) and leaves glibc, the AppImage excludelist's libraries, and the GPU and display stack to the host, so it starts on systems without libxkbcommon-x11 and host Vulkan drivers never bind to bundled copies. On aarch64 the bundled libraries load on 16K- and 64K-page kernels.
- After a fetch or pull, a bookmark whose remote branch was deleted once its pull request merged is cleaned up in one undoable operation; unmerged work is kept, conflicted changes are kept and suggested for abandoning, and the bookmark list shows the deleted remote.
- The file tree shows both entries when a change replaces a file with a directory of the same path.
- On macOS, the toolbar matches the SwiftUI shell's height and button sizes, and its icons render sharp at 18 px.
