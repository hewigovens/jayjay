## Files and review

- Enable **Show all files’ diffs in one list** in Diff settings to scroll through a change. Ctrl+A selects every file when the file list has focus.
- Switch diff layout or open **Edit Diff** from the change header. File rows show a review checkbox at the trailing edge, and marking several files together saves their marks in one operation.
- Large changes list their files while rename detection runs. Syntax highlighting adds Dart, Dockerfile, Just, Protobuf and R, and recognizes more files by name and shebang.

## Working copies and remote repositories

- Working-copy snapshots respect `snapshot.auto-track` and `snapshot.max-new-file-size`. An automatic snapshot failure shows a notice that clears after a successful snapshot.
- If the selected operation disappears during refresh, Restore clears its target.
- A pull request from the same repository uses its head bookmark to name the new workspace. On Linux, remote repository operations can discover your desktop SSH agent.
