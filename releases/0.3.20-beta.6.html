Tags

  • Create a lightweight tag from a change's context menu. The tag chip offers Push while the tag exists only locally, and Delete Tag on Remote once a tracked remote has it; that action asks for confirmation, removes the tag locally, pushes the deletion to every remote that tracks it, and restores the local tag if the push fails. Tags collapsed into the +N overflow chip keep their actions in the change menu.
  • The revset bar gains a Tags preset for tags(), next to Bookmarks.
  • Tab in the revset bar and the revset panel finishes the highlighted completion, or the first one, instead of moving focus; typing tag and pressing Tab gives tags().

Faster on large repositories

  • The Repo Overview builds only the part of the canvas that is on screen. On an overview with about 520 groups and 6,200 change rows, the first render drops from 1.6 s to under 20 ms and a selection change from 1.6 s to under 10 ms.

Fixes

  • On a large repository the bookmark picker no longer opens empty and says there are no bookmarks; it shows Loading bookmarks… until they arrive, and an open panel fills in when they do.
  • Opening a repository no longer blurs the window while it loads. Panes, pickers and diffs that wait for their first content share one loading indicator that names what is loading.
  • Filtering from the Bookmark Manager no longer double-escapes the bookmark name, and keeps local-only and remote-only bookmarks distinct.
  • Commits by coding agents such as Claude Code and GitHub Copilot show the account's GitHub avatar instead of a generated identicon.
